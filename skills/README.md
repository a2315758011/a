# 技能目录

本目录中的每个技能包必须遵循 [SKILL_UPDATE_PROTOCOL.md](./SKILL_UPDATE_PROTOCOL.md)。

## 更新原则

**先审定并修订权威指令源，完成规则验收并冻结版本，再更新对应 Skill。** 如果源指令存在缺陷，不得只修改技能描述掩盖问题。

## 技能包目录

- `manju-director-cn/`：**仅用于 AI 漫剧**，包含剧本转分镜、人物/场景/道具资产、独立自检、自动修复、完整修订稿重写与复检。不包含小游戏或通用工程规则。
- `storyboard-director-cn/`：中文短剧/漫剧分镜导演与独立质检技能，包含 SCG 数据契约和可选校验器。

每个技能的 `SOURCE_LOCK.json` 记录权威来源及版本。技能包是版本快照，不会自动随仓库更新。
