# 小游戏开发工作室 Skill

## 1. 技能定位

本 Skill 是仓库《AI小游戏制作总指令》的专业能力导航与执行补充，不取代根目录 README.md 的 RULE-00—RULE-14，也不复制、覆盖其权威规则。

开始任何任务前：
1. 读取仓库 AGENTS.md，确认领域路由。
2. 读取 README.md 中《AI小游戏制作总指令》，按 RULE-ID 读取本任务章节。
3. 恢复真实项目目录、任务榜单、任务依赖、GitHub 基线、资源版本、运行进程和测试证据。
4. 检查当前可用软件、Skill、MCP、生成网关和平台权限；不能把“知道软件名称”写成“已经安装或可用”。
5. 明确目标平台、核心玩法、屏幕方向、输入方式、目标设备和成功标准。不可逆且无法推断的产品决定才询问用户。

## 2. 引擎选型原则

### 国内小游戏优先路线
- 微信小游戏、抖音小游戏是目标平台时，优先评估 **Cocos Creator 3.8 系列**，使用对应平台官方开发者工具调试与发布。
- 必须先完成目标平台最小构建、启动、输入、生命周期和资源加载探针；版本与限制以执行当天的官方文档为准。
- 同一核心玩法可复用，但微信、抖音分别构建、分别测试，不以浏览器运行代替平台验收。

### 其他路线
- **Phaser + TypeScript + Vite**：适合浏览器优先、H5、PWA 和轻量 2D 游戏。可作为独立路线或原型工具；不能未经平台验证就宣称原生支持微信/抖音小游戏。
- **Godot**：适合独立 2D/3D 游戏及桌面、移动端项目；只有目标平台、插件或导出链经探针证明适配时才选用。
- **Unity**：适合有明确 3D、成熟生态或团队管线需求的项目；先核对许可、成本和目标平台要求，不作为免费默认项。
- 不为形式引入多个引擎。每个游戏项目只设一个主引擎；跨引擎迁移必须有证据证明原路线不满足需求。

## 4. 可复用的已安装专业技能

当前 AI 环境中已有两项相关专业技能，可按任务调用：
- **2D 手机游戏开发总管**：Phaser/TypeScript/Vite 的移动优先 2D 工程、触摸输入、性能预算、浏览器试玩、PWA/Android 证据与发布门禁。它是 Phaser 技术路线技能，不自动替代 Cocos 国内小游戏流程。
- **2D 游戏美术总管**：2D 静态/动态资产、参考一致性、Approved Master、分层、多帧动画、透明通道、锚点、图集、运行时 QA 与引擎导出。

调用美术技能时遵守静态/动态模式确认；角色、敌人、植物、Boss 等动态单位不得用一张静态 PNG 冒充完整动画。共享生成网关优先复用，不重复搭建生图服务。

## 5. 标准生产流程

1. 立项与恢复：读取既有工程和决策，确认项目归属与目标平台。
2. 玩法可视化：按 RULE-00 产出并验收项目玩法总览图。
3. 需求锁定：形成中文 brief、范围、风险和能力矩阵。
4. 玩法策划：形成规则、状态机、数据表和可判定用例。
5. 技术探针：目标平台最小构建、启动、输入、生命周期和资源加载。
6. 可玩原型：实现输入→核心规则→反馈→胜负→重开闭环。
7. 代表性垂直切片：接入真实角色/场景/UI/音效，验证制作到运行的完整链路。
8. 内容生产：先做风格锚点和样例，通过验收后分批扩展。
9. 集成与回归：检查资源 ID、引用、版本、性能和跨模块契约。
10. 平台验收：按目标设备实测构建、输入、屏幕、安全区、生命周期、包体和性能。
11. 发布交付：提供源码、资源、构建版本、运行入口、测试证据、已知限制和恢复说明。

遵循根指令 G0—G4 门禁。G4 未通过不得声称完整交付；真人体验、真实设备或平台账号缺失时明确标为未验证。

## 6. 游戏类型适配

- 塔防：路径、索敌、攻击范围、波次、资源、建造/升级、基地耐久。
- 消除/叠牌：棋盘/卡槽、遮挡、匹配、死局、撤销、随机性与可解性。
- 平台跳跃：移动、跳跃、落地、碰撞、检查点、镜头边界。
- 射击：瞄准、射速、弹道、命中、伤害、刷怪与掉落。
- 放置/经营：离线收益、计时、资源循环、升级成本、存档一致性。
- RPG：角色成长、战斗状态、任务、背包、装备、存档迁移。
类型模板只补充专属规则，不得覆盖用户明确提出的玩法。

## 7. 强制质量约束

- 不以代码存在、页面打开、静态检查或一张截图代替可玩验收。
- 不把占位图、错误透明背景、重复帧或整图平移冒充正式美术和动画。
- 角色身份、场景空间、道具位置、锚点和动作连续性必须保持一致。
- 所有关键按钮必须实际可用；检查重复点击、暂停恢复、重开、异常退出和存档。
- 测试证据必须绑定当前代码 Commit、资源版本和构建标识。
- 失败先定位根因，保存错误证据和恢复点；禁止盲目重复收费生成、覆盖他人修改或删除未知文件。
- 中文为默认交互、目录和报告语言；引擎固定名称和 API 保留原名并说明用途。
