# 小游戏开发软件工具链清单

版本：1.0.0
用途：统一说明各软件的职责、适用平台、费用注意事项和采用条件。**列入清单不代表已安装、已登录、已授权或已通过实际测试。**

## 一、引擎与平台工具

| 软件/平台 | 主要用途 | 推荐场景 | 采用原则 |
|---|---|---|---|
| Cocos Creator 3.8 系列 | 2D/3D 游戏引擎、场景、组件、动画、构建 | 微信/抖音小游戏优先评估 | 国内小游戏主路线；按实际 SDK 与官方要求选具体版本 |
| 微信开发者工具 | 微信小游戏预览、调试、真机体验、上传 | 微信小游戏 | 必须单独验收，不以浏览器测试替代 |
| 抖音开发者工具 | 抖音小游戏调试、预览、发布 | 抖音小游戏 | 单独核实当前平台工具与 SDK |
| Phaser | HTML5 2D 游戏框架 | Web/H5/PWA | 适合浏览器优先项目；平台兼容需实测 |
| Godot | 开源游戏引擎 | 独立 2D/3D、桌面/移动 | 按目标平台导出能力做最小探针 |
| Unity | 商业游戏引擎 | 复杂 3D 或成熟 Unity 项目 | 先核对许可、费用和平台适配，不作为免费默认 |

## 五、测试与发布

- Cocos 编辑器内预览：验证场景、资源引用、动画与脚本。
- 微信开发者工具：微信构建、调试、真机预览和平台发布检查。
- 抖音开发者工具：抖音构建、调试、真机预览和平台发布检查。
- Chrome/Edge：Web 运行、控制台、网络、帧时间和响应式检查。
- Android Studio / Android 真机：安装、触摸、屏幕、安全区、生命周期、性能和日志。
- GitHub Actions：在工作流确实配置并运行后用于自动化构建/测试；不能仅因仓库存在就宣称 CI 已启用。

## 六、默认技术组合

### 微信/抖音小游戏
Cocos Creator + 对应官方开发者工具 + VS Code（按需）+ GitHub Desktop + Krita/GIMP + Audacity。Tiled/LDtk、Blender、Android Studio 按项目需要添加。

### 浏览器/H5 小游戏
Phaser + TypeScript + Vite + VS Code + Chrome/Edge DevTools + GitHub Desktop。需要安装式体验时再评估 PWA；需要原生封装时另做设备探针。

### 独立桌面/移动游戏
根据已有工程和目标平台选择 Godot、Cocos 或 Unity；优先复用已有主引擎，不因工具清单而迁移。

## 七、安装与版本治理

1. 安装前检查电脑现有版本、项目要求、磁盘空间、许可证和平台 SDK。
2. 优先复用已安装软件，不重复安装或覆盖项目指定版本。
3. 版本写入项目的“工程目录说明.md”或“项目文档/技术环境.md”。
4. 版本升级先在隔离分支/副本做构建与回归，不直接升级生产工程。
5. 软件费用、商用授权、素材许可和平台规则执行前查看官方最新条款。
6. 用户偏好免费工具；付费软件只列为可选，不自动购买、不自动订阅。
7. 本清单不是安装证明。每个项目维护 capability-matrix：软件/版本、可用状态、权限、最小探针、结果、限制和替代方案。
