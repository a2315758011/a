# AI 漫剧导演技能 V1.0.7

这是**漫剧专用**技能，包含剧本转分镜、完整独立自检、自动修复并重新输出完整修订终稿，以及漫剧人物/场景/道具资产制作规则。

## 文件
- `SKILL.md`：漫剧任务识别、加载及自检修复闭环。
- `references/剧本转分镜指令.md`：完整分镜编写原文。
- `references/剧本转分镜自检指令.md`：完整自检原文，要求完整修订稿及复检。
- `references/AIGC人物资产指令.md`：漫剧人物、场景和资产规则原文。
- `SOURCE_LOCK.json`：原始文件 Git blob SHA 与版本锁定。

只保留漫剧制作所需的三份权威规则。

## 使用
支持 Agent Skills 的 AI 可导入整个文件夹，必须连同 references 一起保存。普通 ChatGPT 不保证直接安装技能 ZIP；可将 SKILL.md 内容用于自定义 GPT 指令，将所需 references 作为 Knowledge 上传。是否有 Skills 安装功能以账号和产品实际界面为准。

## 维护
源指令先修订与验收，来源版本冻结后再更新技能，检查包内原文 SHA 与引用完整性，通过后才发布。详见上一级目录的 SKILL_UPDATE_PROTOCOL.md。

## 验收范围
文件存在、引用完整、原文一致可通过结构核验；模型实际读取、自检质量、视频生成与镜头一致性必须另外做真实任务测试，不得混同。

## V1.0.3 构图修正

- 人物近景严格以肩部以上至头顶为实际裁切范围；两名全身火柴人不算近景。
- 每镜明确身体正背、左右侧及四分之三朝向，头部朝向和视线另列。
- SVG 必须可核对人体朝向；不一致时自检判错、重画构图并交付完整修订终稿。

## V1.0.3 景别参考图约束

以用户提供的五级取景示意（远景、全景、中景、近景、特写）校验 SVG 的真实人体裁切。禁止通过改变标签而不重画错误的画面。同步更新分镜原文和独立自检规则至 V2.8.6。

## 1.0.3 SVG 构图修复

版本 V2.8.6 强制 SVG 按真实镜头视口绘制。近景主角肩部以上并占据画面主体，前景角色仅显示后脑/肩部局部；禁止将完整人物缩小后标注近景。错误时必须重画 SVG、同步修改分镜正文、输出完整修订稿并再次复检。

## V1.0.7 空间连续性门禁（分镜规则 V2.8.9）

双人近景、过肩镜头生成前，先检查人物站位、相互距离、机位轴线及上一镜尾态。不得为了同框将原本相距较远的人物强行移动到一起。无法在原位真实同框时，优先使用单人近景、画外人物、正反打或保持真实距离的中远景。无动作依据的位移属于严重连续性错误。SVG 只记录位置、动作、道具和轴线，画不清时可以省略。

## V2.8.9 双人近景空间检查

镜头景别不能改变人物世界坐标。两人原本相距较远时，无来源的双人近景/贴近前景构图会诱发提示词污染；必须优先改为单人近景 + 画外人物或符合轴线的正反打，必要时保留远景交代站位。没有合法走位而瞬间靠近，P0 阻断；修复后输出完整分镜再复检。SVG 只记录位置/动作/道具，可画不清时不画。
