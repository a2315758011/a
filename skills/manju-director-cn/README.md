# AI 漫剧导演技能 V1.0.0

这是**漫剧专用**技能，包含剧本转分镜、完整独立自检、自动修复并重新输出完整修订终稿，以及漫剧人物/场景/道具资产制作规则。

## 文件
- `SKILL.md`：漫剧任务识别、加载及自检修复闭环。
- `references/剧本转分镜指令.md`：完整分镜编写原文。
- `references/剧本转分镜自检指令.md`：完整自检原文，要求完整修订稿及复检。
- `references/AIGC人物资产指令.md`：漫剧人物、场景和资产规则原文。
- `SOURCE_LOCK.json`：原始文件 Git blob SHA 与版本锁定。

只保留漫剧制作所需的三份权威规则。

## 使用
支持 Agent Skills 的 AI 可导入整个文件夹，必须连同 references 一起保存。普通 ChatGPT 不保证直接安装技能 ZIP；可将 SKILL.md 内容用于自定义 GPT 指令，将所需 references 作为 Knowledge 上传。是否有 Skills 安装功能以账号和产品实际界面为准。

## 维护
源指令先修订与验收，来源版本冻结后再更新技能，检查包内原文 SHA 与引用完整性，通过后才发布。详见上一级目录的 SKILL_UPDATE_PROTOCOL.md。

## 验收范围
文件存在、引用完整、原文一致可通过结构核验；模型实际读取、自检质量、视频生成与镜头一致性必须另外做真实任务测试，不得混同。
