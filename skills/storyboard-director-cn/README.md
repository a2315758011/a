# 学员分镜导演技能包 V4.0（分层规则）

此技能以完整的 V2.8.3 基础编写/自检规则为底座，叠加 V4.0 导演决策与独立验收规则。V4 增加戏剧因果、观众可观察性、战术变化、情绪代价、动作时间/并行事件审计和分层验收，不删除已有 source、SCG、资产和连续性门禁。

## 最简单的使用方式
1. 支持 Agent Skills 的客户端：从仓库下载完整的 skills/storyboard-director-cn 文件夹并安装。
2. 普通聊天客户端：下载仓库根目录的 学员分镜双规则完整版-V4.0.md，将它作为附件上传；再上传剧本并说“开始分镜”。
3. 若剧本已在当前对话中，直接说“开始分镜”即可。只审不改说“只审核分镜”；初稿后等待用户审核说“逐阶段审核”。

## 规则与程序
- 必须联合读取两份基础规则和两份 V4 规则。
- Node.js 可用时运行 scripts/分镜事件时长校验器-V4.js tests/分镜时间回归样例-V4.json；只有实际运行且退出码为 0 才可报告程序测试通过。
- 旧 V2.8.1 ZIP 是历史快照，不包含本次 V4.0 增量规则，不能当成 V4 安装包。本仓库技能目录可作为 V4 源文件，但在生成/验证新的二进制 ZIP 前，不宣称旧 ZIP 已同步。
- 离线快照不自动随 GitHub 更新；教师更新规则后必须更新 SOURCE_LOCK 并重新生成包。
