# 学员分镜导演技能包 · V2.8.6 离线版（发行 1.1.0）

这是一个符合 Agent Skills 基本目录约定的技能包，包含 `SKILL.md`、两份**完整 V2.9.1** 规则原文、SCG 数据契约、可选 Node.js 校验器与回归样例。不需要 GitHub 插件、MCP 或网络连接来读取已安装的规则。

## 安装方法
- **支持 Agent Skills 的 AI 工具**：解压 ZIP，复制完整的 `storyboard-director-cn` 文件夹到该工具的 Skills 安装目录；或使用该工具提供的技能包导入功能。文件夹名必须保留为 `storyboard-director-cn`。该格式符合开放规范，但不同工具具体安装入口不一样。
- **仓库方式**：文件同步公开在 https://github.com/a2315758011/a/tree/main/skills/storyboard-director-cn 。支持扫描标准 `skills/` 目录的安装器可直接从仓库导入。
- **普通 AI 聊天，没有 Skills 安装功能**：将解压后的 `SKILL.md`、`references/剧本转分镜指令.md`、`references/剧本转分镜自检指令.md` 作为文件上传到同一对话（如果平台支持批量上传）。发送 ZIP 本身未必能让模型读取 ZIP 内的所有文件；该场景需要上传解压文件或粘贴全文。把网址交给没有联网读取能力的 AI 不会自动变为技能。
- **开始使用**：提供剧本并说“按分镜导演技能编写并独立自检，修复 P0/P1 后交付完整分镜”。只审不修则明确说“只审核不修改”。

## 安全与版本
- 两份规则包含完整正文，没有替换成网页链接，也没有删改专业门禁。
- 本包从公开仓库 `a2315758011/a` 的 `main` 分支快照生成，规则版本 **V2.8.6**，来源 SHA 在 SOURCE_LOCK.json。
- 这是**快照**，不会自动随着 GitHub 更新。教师更新两份原文后要重新打包，学员重新安装才能使用新版。

## V1.1.0 景别与朝向修正

已同步权威分镜编写、自检指令 V2.8.6。SVG 依照远景（全身+环境）/全景（全身）/中景（腰腹以上）/近景（肩部以上）/特写（头脸局部）绘制，不得以站位图替代镜头构图。角色正背朝向必须可辨；错误先修复、完整重写分镜与 SVG、再复检。

## 1.0.4 SVG 构图修复

版本 V2.8.6 强制 SVG 按真实镜头视口绘制。近景主角肩部以上并占据画面主体，前景角色仅显示后脑/肩部局部；禁止将完整人物缩小后标注近景。错误时必须重画 SVG、同步修改分镜正文、输出完整修订稿并再次复检。

## 1.0.7 SVG 用途修正（V2.8.8）

SVG 只用于记录人物位置、动作路径、身体朝向、道具持有/摆放、前后景和镜头轴线，不是正式画面或角色美术。图示无法清楚表达时，不要硬画；用准确文字描述并标注未绘原因。

## V1.1.0 空间连续性门禁（分镜规则 V2.8.9）

双人近景/过肩前景不得覆盖既定人物空间位置。先核对角色距离、机位、轴线及前镜尾态；同框不合理时改为单人近景、画外人物、正反打或保留真实距离的景别。未经动作授权的人物位移判严重错误，必须修复受影响镜头并重新输出完整分镜。SVG 仅作动作、道具、位置关系示意，无法画清可不画。

## V2.8.9 双人近景空间检查

镜头景别不能改变人物世界坐标。两人原本相距较远时，无来源的双人近景/贴近前景构图会诱发提示词污染；必须优先改为单人近景 + 画外人物或符合轴线的正反打，必要时保留远景交代站位。没有合法走位而瞬间靠近，P0 阻断；修复后输出完整分镜再复检。SVG 只记录位置/动作/道具，可画不清时不画。

## 1.0.9 · V2.9.1 空间状态账本

新增内部人物/道具/摄影机状态账本、事实来源标签、镜头约束编译、跨镜状态传递与反例压力测试。景别不改变人物世界坐标；无走位不得为了双人近景强行靠近。内部 SVG 默认不输出，也不是验收指标。以权威源指令及 SOURCE_LOCK.json 为准。

## V2.10.0 剧本联想与主动问题发现

在分镜前推演目标、阻力、因果、人物动机、信息来源、状态后果、伏笔与观众信息；区分原文事实、必然推论、非唯一推断和缺失矛盾。禁止把联想当成事实擅自改写剧情。独立自检须区分剧本缺口与分镜错误，修复后重写完整分镜并复检。
