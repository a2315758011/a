# 剧本转分镜导演与独立质检技能 V1.1.3（学员离线版）

本 Skill 面向学员，解决“无法访问作者仓库获取指令”的问题。安装/导入后，学员只需提供剧本或待审分镜；主编写规则与独立自检规则已随包内置，不需要访问仓库、安装 MCP 或手工复制长指令。

## 本版内容
- 编写规则：V2.10.1
- 独立自检规则：V2.10.1
- 分镜导演推演：视觉节拍、动作链、表演可见证据、镜头功能、观众视点和模型可执行性。
- 空间连续性：人物世界位置、身体朝向、视线、景别裁切、道具持有与跨镜状态。
- 自检修复闭环：发现 P0/P1 问题 → 修复最早冲突镜头 → 检查关联镜头 → 输出完整终稿。
- 可选 SCG 数据契约、回归样例和 Node.js 校验器。
- 高风险动作时序校验：持续动作、前置依赖、互斥动作、机关接合与逐人可见展示的结构化事件时间账本。
- 默认不输出 SVG；内部示意图不作为交付要求。

## 程序校验命令

在 Skill 根目录执行对应命令：

```bash
node scripts/分镜SCG校验器-V1.js tests/分镜SCG回归样例-V1.json
node scripts/分镜事件时长校验器-V1.js tests/分镜事件时长回归样例-V1.json
```

第二个命令针对高风险动作时序的结构化事件账本。它不解析普通中文稿，也不证明生成视频执行成功；估算时长只触发待复核警告。

## 学员使用方式
1. 将整个 `storyboard-director-cn` 文件夹作为一个 Skill 导入/提供给支持本地 Skill 的 AI 客户端。
2. 提供原剧本或现有分镜，并说明需要“生成分镜”还是“审核并修复”。
3. Skill 会先完整读取包内两份规则，再编写、独立自检、修复并输出完整修订稿。
4. 若程序校验未执行或真实视频未生成，AI 必须如实标注，不能把文本审核说成视频验收。

## 重要限制
- 必须完整下载/导入 `storyboard-director-cn` 文件夹，不能只复制 `SKILL.md`；两份 `references` 主规则是必要文件。
- 历史 ZIP V2.8.1 已过期，不作为当前 Skill 安装包。
- 如主规则缺失、损坏或被截断，必须报告具体文件，不能用摘要代替。
- 本地离线包代表打包时的规则快照。作者更新仓库后，需要重新生成并分发新版本 ZIP；旧包不会自动更新。
- SCG 校验为按需执行项；高风险时序场景应运行事件时长校验器。两者均需 Node.js。
- 事件时长校验器只检查结构化事件账本，不解析普通中文稿，也不验证真实生成视频；估算阈值只产生待复核警告，不冒充实测失败。无 Node.js 时必须注明相应程序校验未执行。
