# 剧本转分镜导演与独立质检技能（离线版）

## 适用场景与启动
- 当用户提交剧本，要求**编写、生成、改写、继续、修复、审核** AI 短剧/漫剧/真人视频的分镜时，自动调用本技能。
- 学员无需设置角色、访问仓库、安装MCP或掌握程序命令。用户只需提供**原剧本（或待审分镜）**及已有的相关人物/场景素材。
- 本技能为**完整离线规则快照 V2.8**；不得声称已联网核对GitHub最新规则。用户明确提供更新的权威规则时，以其完整版本替换相应快照。

## 激活后的必读顺序（不能只阅读本页）
1. **完整读取** [剧本转分镜指令](references/剧本转分镜指令.md)。
2. **完整读取** [剧本转分镜自检指令](references/剧本转分镜自检指令.md)。
3. 确认两份均能从已安装技能目录读取，不可把链接文字、文件名、摘要视为已读取全文。若无法读取，报告缺失文件路径；不伪称规则已加载。
4. 本地文件可读取时，不要求执行任何网络 fetch；外部 GitHub 访问失败不能阻断本地模式。
5. 原规则如涉及 SCG 审核，按需读取 [SCG 数据契约](references/分镜SCG数据契约-V1.md)。若有 Node.js 和结构化测试数据，可运行下方校验器；没有时用模型逐项检查，并标注**SCG程序校验未执行**，不得伪造程序PASS。

## 执行流程
1. **事实锁定**：恢复原剧本、人物服装、场景布局、关键道具、台词、参考资产、目标视频模型真实能力。看不到或未提供的素材标注未取得，不虚构。
2. **剧情覆盖与压缩决策**：先分场、识别剧情事件与连续动作单元，内部区分重点镜头、功能镜头和过桥镜头；功能镜头按观众理解所需的最短时长表达，不按10秒/15秒档位倒推剧情。尊重原剧本的完整对白与因果。
3. **正式编写**：按 `references/剧本转分镜指令.md` 的完整规则产出可以拍摄、可以生成的镜头；优先剧情、导演表现、动作可完成性及道具物理连续性。不要让内部 SCG、ID、错误码占据正文。
4. **独立审核**：切换独立审稿视角，按 `references/剧本转分镜自检指令.md` 核对原剧本覆盖、对白、时长/信息量匹配、功能镜头是否冗长、关键接触与因果链、镜头轴线、站位/左右手/抓握、容器/遮挡/可见性、资产、噪音、后期文字及跨段接续。
5. **直接修复**：默认对 P0/P1 自动修复，再从头复检，直到 P0=0、P1=0 或指出无法自主解决的真正阻断。用户明确要求“只审核不修改”时才只返回审计问题。
6. **交付正文**：默认仅输出**完整修订分镜**，不附冗长的检验账本。只有存在无法验证的关键事实、能力或资产时，在末尾简短注明；用户需要跨集接力时，再按原规则输出必要的 Handoff SCG 附录。

## 景别与身体朝向硬性验收（V2.8.8）

- 分镜正文必须写清景别、身体正背/侧面、头部朝向和视线方向。
- SVG 只记录人物位置、动作路径、道具状态/持有关系、前后景和镜头轴线；它不是角色美术图、镜头效果图或景别证明图。
- 可用简单符号、箭头、编号和图例表达。若图示无法清楚传达或会误导，**不要画该镜 SVG**，改用准确文字说明并注明未绘原因。不得为了每镜一图硬画火柴人。
- 旧版要求 SVG 必须呈现实际相机裁切或充当正式视觉预览的条款，以 V2.8.8 本节为准。

## 特别重要的验收边界
- **规则加载**、**模型文字审稿**、**程序SCG校验**、**实际生成视频测试**是四种不同状态，分别报告，绝不相互冒充。
- 没有原剧本不能宣称剧情覆盖通过；没有真实视频模型能力信息不能宣称生成时长可执行性最终通过。
- 切点不能断在抬手、交接、起身、开门、半句对白等不可稳定恢复的中间态；书包内的手机不能无动作瞬移到书包外，屏幕文字要满足物理可见性。
- 实际有程序环境时，先跑回归测试，随后才对实际 SCG 数据进行校验；退出码 0 **仅**证明校验器已经实现的规则通过。
- 技能本身不能赋予AI不存在的程序、视频生成、浏览器或文件读取权限，也不能自动变成平台原生安装功能。

## 可选程序校验（无 Node.js 可跳过，标注未执行）
运行相对于技能根目录的：
```bash
node scripts/分镜SCG校验器-V1.js tests/分镜SCG回归样例-V1.json
```
回归通过后，才可用同一校验器检查按契约编写的实际 `{"cases":[{"case_id":"...","expected_ok":true,"expected_errors":[],"scene":{"shots":[...]}}]}` 数据。**没有结构化实际数据不能声称对本次分镜跑过程序校验。**

## 双人近景空间连续性门禁（V2.8.9）

原本距离较远的两个人不能为了“双人近景/过肩”突然出现在一起。先读取人物站位、距离、上一镜尾态、机位轴线；同框不可实现时改用单人近景、画外人物、正反打或远景。没有走位动作却出现位置跳变，独立自检判 P0，修复全部受影响镜头，再交付完整修订稿。SVG 仅作位置、动作与道具辅助记录，画不清可省略。

## 空间状态账本与镜头约束编译（V2.9.1）

生成分镜前建立内部人物/道具/摄影机状态账本：位置与相对距离、身体/头部朝向、视线、动作起止、道具唯一 ID 与持有者、机位与轴线、画内外和遮挡。事实来源标记为原文明确、素材可证、推断或未知；未知不得自动补全，精确距离必须有来源。

景别只改变取景，不改变人物世界坐标。两人原本相距较远时，不得为了双人近景或过肩构图强行靠近。没有走位事件时优先单人近景、画外人物、正反打或真实可行的中远景。道具换手必须有交接动作。每镜记录开始状态、动作、结束状态，并与前后镜衔接。

压力测试远距离双人近景、人物左右换位、无动作进出画、道具无交接换手、视线错位、跨轴和动作首尾不一致。失败时修复最早冲突镜头、复查上下游并输出完整修订稿。内部状态表或 SVG 只是可选推理工具，默认不输出，不以 SVG 数量验收。

## 剧本联想推演与问题发现（V2.10.0）

正式拆镜前主动检查角色目标、阻力、行动结果、动机、信息来源、时间空间可行性、道具/伤势后果、伏笔回收、观众信息和镜头叙事价值。把发现分为原文明确、必然推论、合理但非唯一解释、信息缺失/矛盾。前两者可作为约束；推断不得冒充事实；关键缺口不能私自补剧情。独立自检要区分原剧本缺口与分镜表达错误，修复后重写完整分镜并复检。内部分析默认不输出；最终不附 SVG。
