# 剧本转分镜导演与独立质检技能（离线版）

## 适用场景与启动
- 当用户提交剧本，要求**编写、生成、改写、继续、修复、审核** AI 短剧/漫剧/真人视频的分镜时，自动调用本技能。
- 学员无需设置角色、访问仓库、安装MCP或掌握程序命令。用户只需提供**原剧本（或待审分镜）**及已有的相关人物/场景素材。
- 本技能为**完整离线规则快照 V2.8**；不得声称已联网核对GitHub最新规则。用户明确提供更新的权威规则时，以其完整版本替换相应快照。

## 分阶段必读顺序｜初稿前不得读取自检规则

1. **初稿前只完整读取** `references/剧本转分镜指令.md`。不能只阅读本页、文件名、摘要或部分正文。
2. 在完整初稿完成前，**禁止打开或读取** `references/剧本转分镜自检指令.md` 的正文；即使两份文件位于同一技能目录，也必须遵守此顺序。
3. 依据完整编写规则恢复原剧本与已确认资产，建立剧情覆盖映射，编写本次任务范围内的完整初稿，并同时生成符合 SCG 数据契约的独立结构化 SCG 文件。两者共同构成【初稿 V0｜带 SCG 审核包】，不得将 SCG 字段混入镜头生成正文。先保存到 GPT 云端文件库并读回核验，再冻结为审核基线。
4. **只有完整初稿已完成并冻结后**，才完整读取 `references/剧本转分镜自检指令.md`。若无法读取全文，保留初稿，报告实际缺失或读取错误，停止正式审核、修复及最终放行。
5. 审核阶段先独立检查带 SCG 的冻结初稿并生成【审核问题交接单】，将问题单保存到 GPT 云端并读回核验，再把原剧本、初稿、SCG、问题单、已确认设定/资产及两份完整规则交给修复阶段。问题单至少包含严重度、具体镜头、事实依据、规则冲突、修复要求和受影响镜头。
6. 若有可实际调用的独立审核/修复 Agent，可分别交接；否则由当前 AI 严格按“审核并形成问题单 → 切换修复阶段 → 复检”的顺序执行，不得谎称调用了其他 Agent。
7. 修复后同步更新分镜正文与 SCG，再按自检规则审核完整修订稿。能够自主解决的 P0/P1 必须继续修复；无法解决时明确阻断，不得伪称通过。最终输出必须另生成不带 SCG 的人类可读版，并将初稿、SCG、问题单、修复/复检记录、终稿及证据清单持久保存到 GPT 云端文件库；每份文件均须读回核验。禁止把本地文件当作最终证据。

## 执行流程

1. **规则阶段门禁**：严格按上述顺序，先加载编写规则，完成并冻结初稿，再加载自检规则。不得把两份规则的读取合并到初稿之前。
2. **事实锁定**：恢复原剧本、人物服装、场景布局、关键道具、台词、参考资产、目标视频模型真实能力。看不到或未提供的素材标注未取得，不虚构。
3. **剧情覆盖与压缩决策**：先分场、识别剧情事件与连续动作单元，内部区分重点镜头、功能镜头和过桥镜头；功能镜头按观众理解所需的最短时长表达，不按10秒/15秒档位倒推剧情。尊重原剧本的完整对白与因果。
4. **正式编写**：按 `references/剧本转分镜指令.md` 的完整规则产出可以拍摄、可以生成的镜头；优先剧情、导演表现、动作可完成性及道具物理连续性。不要让内部 SCG、ID、错误码占据正文。
5. **独立审核与问题交接**：初稿冻结且完整自检规则加载成功后，先逐项审核，不在审核阶段直接改稿；形成有证据的 P0/P1/P2 问题交接单。
6. **修复模型修改**：将原剧本、初稿和问题交接单连同规则交给修复阶段，逐项修改可解决问题。不得只返回问题清单或修改建议。
7. **全稿复检**：修复后重新检查受影响镜头及全稿；P0/P1 未归零时继续修复复检，或明确标记真实阻断。
8. **交付正文**：默认仅输出**不带 SCG 的完整修订分镜**，不附冗长的检验账本。只有存在无法验证的关键事实、能力或资产时，在末尾简短注明；用户需要跨集接力时，再按原规则输出必要的 Handoff SCG 附录。

9. **可信证据云端门禁**：每次任务建立唯一 run_id 和 GPT 云端证据目录，保存规则读取凭据、带 SCG 初稿、SCG JSON、审核问题单、修复与复检记录、不带 SCG 的终稿和证据清单。每个关键阶段先云端写入、再读回核验；没有云端写入/读回能力时标记【云端证据门禁受阻】，不得回退到本地作为最终保存位置，也不得宣称完整交付。

## 特别重要的验收边界
- **编写规则加载**、**初稿完成**、**自检规则加载**、**模型文字审稿**、**程序 SCG 校验**、**实际生成视频测试**是不同状态，必须按顺序和真实证据分别报告。
- 没有原剧本不能宣称剧情覆盖通过；没有真实视频模型能力信息不能宣称生成时长可执行性最终通过。
- 切点不能断在抬手、交接、起身、开门、半句对白等不可稳定恢复的中间态；书包内的手机不能无动作瞬移到书包外，屏幕文字要满足物理可见性。
- 实际有程序环境时，先跑回归测试，随后才对实际 SCG 数据进行校验；退出码 0 **仅**证明校验器已经实现的规则通过。
- 技能本身不能赋予AI不存在的程序、视频生成、浏览器或文件读取权限，也不能自动变成平台原生安装功能。

## 可选程序校验（无 Node.js 可跳过，标注未执行）
运行相对于技能根目录的：
```bash
node scripts/分镜SCG校验器-V1.js tests/分镜SCG回归样例-V1.json
```
回归通过后，才可用同一校验器检查按契约编写的实际 `{"cases":[{"case_id":"...","expected_ok":true,"expected_errors":[],"scene":{"shots":[...]}}]}` 数据。**没有结构化实际数据不能声称对本次分镜跑过程序校验。**
