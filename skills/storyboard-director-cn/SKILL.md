# 剧本转分镜导演与独立质检技能（学员版）

## 学员如何使用
学员只需提供：
- 原剧本、分场剧本，或需要修订的分镜；
- 已有的人物、场景、道具参考素材（如果有）；
- 视频模型与目标时长（如果已确定）。

不要求学员登录作者的 GitHub、访问私有仓库、安装 MCP、编写代码或手动拼接多份指令。两份完整权威规则随技能包一并提供，按本地文件读取即可。

## 启动时必须完整读取
1. `references/剧本转分镜指令.md`：主编写规则，V2.10.1。
2. `references/剧本转分镜自检指令.md`：独立审核与修复规则，V2.10.1。
3. 根据任务需要读取 `references/分镜SCG数据契约-V1.md`、`references/分镜穿帮专项回归样例-V1.md`。
4. 需要运行程序校验时，读取 `scripts/分镜SCG校验器-V1.js` 和 `tests/分镜SCG回归样例-V1.json`。

必须确认主编写规则和自检规则都已从技能目录完整读取。若文件缺失、读取截断或内容不可访问，明确报告具体文件和阻塞原因；不得声称已加载，也不得用摘要替代全文。

## 执行流程
1. **锁定原始事实**：读取原剧本、人物/服装/场景/道具素材、台词与用户约束。区分原文明确、素材可证、推断与未知；未知不能伪装成事实。
2. **导演推演**：先拆分观众必须理解的视觉节拍，再设计镜头。主动检查信息揭示、动作因果、情绪落点、必要反应、镜头新增信息与节奏功能；不擅自改写剧情。
3. **编写完整分镜**：按主规则逐镜写清主体、景别与实际裁切、身体朝向、头部朝向、视线目标、机位/轴线、可观察动作、动作方向与结果、道具状态、台词/声音、时长及与前后镜的衔接。
4. **独立自检**：切换独立审稿视角，使用自检规则核查原剧本覆盖、动作链、观众信息、镜头功能、景别、身体朝向、空间距离、轴线、视线、左右手、道具交接、时长、模型可执行性与提示词污染。
5. **直接修复并复检**：默认对可自主修复的 P0/P1 问题修复，复查受影响的前后镜头，再重写完整分镜终稿。用户明确要求“只审核、不改稿”时才只输出审计结果。
6. **交付**：默认交付完整、可直接使用的分镜正文；简要说明已修复问题及尚未验证项。不要把内部账本、SCG、分析日志或 SVG 混进最终分镜正文，除非用户明确要求查看。
7. **如实报告验证**：区分文本审核、SCG 程序校验、素材核验与真实视频生成测试。没有实际运行的程序或生成的视频，不得宣称已通过相应测试。

## 必须遵守的分镜设计原则
- 先判断每镜的叙事任务，再选景别、机位、运镜和时长；不能只把台词逐句换成画面。
- 动作链需要观众理解的起点、关键接触/变化、结果与必要反应；不跳过必要步骤，也不机械地把普通动作拆成冗余镜头。
- 情绪词要转成可观察的表演证据，例如视线停顿、下颌绷紧、手指收紧、呼吸变化、动作迟疑或身体重心变化。
- 近景必须符合实际裁切范围；身体朝向、头部朝向与视线方向分开写清。
- 景别只改变摄影机取景，不改变人物世界位置。远距离人物不能为了双人近景、过肩或同框而无依据地靠近。
- 道具持有者、左右手、位置、开合与损坏状态只能通过有依据的动作事件变化。
- 每镜只写当前镜头需要模型执行的可见信息。删除无关背景清单、重复负面词与互相冲突的运镜/动作要求。
- SVG 不是必需产物。画不清、会误导或没有额外信息价值时不要画；不得用 SVG 数量验收分镜质量。

## 可选 SCG 程序校验
具备 Node.js 时，可在技能根目录运行：

```bash
node scripts/分镜SCG校验器-V1.js tests/分镜SCG回归样例-V1.json
```

运行后按真实退出码和输出报告结果。没有 Node.js 时可以跳过程序校验，继续执行模型逐项自检，并明确标记“SCG 程序校验未执行”。通过回归样例不等于本次真实分镜或最终视频已通过验证。
