# 分镜导演技能 V4.0

## 强制读取顺序
1. 读取 references/剧本转分镜指令.md 全文（基础规则 V2.10.1，保留 source、SCG、资产和状态门禁）。
2. 读取 references/剧本转分镜自检指令.md 全文（基础自检规则）。
3. 读取 references/剧本转分镜指令-V4.md 全文（导演决策、空间调度、战斗、情绪和时间事件图）。
4. 读取 references/剧本转分镜自检指令-V4.md 全文（独立验收门禁）。
5. 有 Node.js 时运行 scripts/分镜事件时长校验器-V4.js tests/分镜时间回归样例-V4.json；再运行已有 SCG 校验器和回归样例。
6. 对正式任务记录规则版本与来源。离线快照必须标记在线最新版未核验。

## 调度行为
- 用户只需附剧本并说“开始分镜”；同一对话已提供剧本时不重复索取。
- 默认自动完成导演设计、初稿、基础自检、V4 独立审查、P0/P1 修复、复检和交付；“逐阶段审核”才在初稿后暂停。
- 先确定每场戏的目标、阻碍、策略变化、观众信息、代价、情绪曲线和出口状态，再写镜头。
- 每个关键镜头检查起态、视觉焦点、动作路径/接触/结果、机位、切镜动机、声音和退出状态。
- 打斗必须有战术目标、攻击线、反制、可见接触、局势变化和代价；特效不得遮掉主攻线和命中结果。
- 区分镜头展示时间与故事事件时间，审查持续操作起点、串行依赖、合法并行、人物/独占资源冲突及群像展示负载。
- 文本审核、程序校验、白模预演、关键帧、视频 Take、成片和用户审核分别记录；不得互相冒充。
- 只有真实调用独立 Agent 才能称多智能体并行；否则按岗位分阶段复核。
- 无工具时继续完成能做的文本工作，明确未执行项，不虚构测试或文件。

## 文件
- 基础规则：references/剧本转分镜指令.md、references/剧本转分镜自检指令.md
- V4 增量规则：references/剧本转分镜指令-V4.md、references/剧本转分镜自检指令-V4.md
- 时间校验器：scripts/分镜事件时长校验器-V4.js
- 时间回归样例：tests/分镜时间回归样例-V4.json
- 原 SCG 校验器/测试与连续性回归文件保留，不得删除。

## 重要边界
V4 校验器只检查结构化事件账本，不会自动理解任意中文剧本，也不能替代白模或实际视频逐帧验收。旧 ZIP 是历史快照，不能称为 V4；当前 V4 正文和来源锁必须核对后才可发布新版包。
