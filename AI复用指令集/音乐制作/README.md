# 音乐制作指令

本目录采用**按需调用**，不是每首歌强制执行所有专业模块。

## 文件

- [真实经历短歌专业制作人总指令.md](./真实经历短歌专业制作人总指令.md)：总规则。先判断歌曲需要什么，再选择歌词、曲谱、歌手、编曲、调音、混音或母带模块。
- [作品案例/等你发现_专业短歌制作方案.md](./作品案例/等你发现_专业短歌制作方案.md)：使用总规则完成的示例，展示如何只保留对歌曲有增益的部分。

## 使用方式

1. 把真实经历直接附在总指令后面。
2. 说明交付层级：只要歌词、需要可唱曲谱，或需要完整制作指令。
3. 如果没有特别说明，AI 应自行判断最合适的交付层级，不必反复询问普通技术细节。
4. 只有实际拿到音频后，才能报告真实音准、音色、混音和母带验收结果。

## 核心原则

**专业不是把所有技术都用上，而是知道哪一个细节、哪一个音符、哪一种处理最能提升这首歌；其余全部删掉。**
