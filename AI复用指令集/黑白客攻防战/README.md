## 当前云端版本

**V8.0｜自适应人类对手与深度决策内核｜2026-10-22**

本轮已完成联网研究和30轮可审计对抗升级。核心变化：

- 默认人类对手会阅读规则、观察响应并跨轮变招；
- 区分真实规则、用户流程要求、事实主张、当前观察、记忆和推断；
- 对具体动作判断，不因对象标签导致整个任务停摆；
- 防止AI拿自己的旧报告/合同证明自己的旧判断；
- 元规则核验有时间预算，防止规则DoS拖光30分钟；
- 跟踪PLAN→MEMORY→RETRIEVAL→TOOL→ACTION→EVALUATOR跨阶段污染；
- 工具证据必须真正改变假设和下一步，单独检查tool-to-agent gap；
- 强制正常任务对照，避免“什么都拒绝”获得虚假高分；
- 使用最小差异pairwise、自适应多轮序列和deployment-like对照；
- 真实业务结果优先于评分器、报告和流程代理指标。
