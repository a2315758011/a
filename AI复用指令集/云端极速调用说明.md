# 云端极速调用 V1 — 实测与限制

目标：云端保存经过审核的脚本；本地仅保留很小的索引、调用器与系统临时缓存。

调用命令：
- `node 云端极速调用.js find 扫描`
- `node 云端极速调用.js prefetch file-inventory`
- `node 云端极速调用.js run file-inventory 脚本`

性能原则：
1. 先检索本地轻量索引，不联网；
2. 优先使用按 SHA256 标识的操作系统临时缓存，并在运行前重新验证哈希；
3. 缓存未命中时从 GitHub 获取，哈希不一致拒绝执行；
4. 直接缓存复用已编译/已验证操作，避免重复 AI 推理与 GUI 点击；
5. 本地临时缓存可由系统清理，GitHub 为源码真源。

验收记录（2026-10-22）：`find 扫描` 成功；Node `--check` 成功；从已审核本地原件种入临时缓存后，file-inventory 连续两次返回码 0，子进程实测 48.1ms、46.5ms。**GitHub 首次直连预取未通过，因此冷启动联网获取尚未验收。**`project-bootstrap` 仍依赖本地脚本相对路径，不视为纯云运行。没有删除现有本地备份。

安全要求：所有云端脚本需要在白名单并匹配 SHA256，缓存内容不满足哈希则不执行。不允许通过公开 GitHub 发布敏感机器配置。
