# AI 复用库统一执行规范 V1.1

本目录是跨 AI、跨项目的可执行操作复用库。先复用已有脚本，后考虑新建。

## 强制门禁
1. 操作前先运行 `node 复用管理器.js find <关键词>`，找到后 `show <ID>` 检查参数、适用环境、风险，再 `run <ID>`。
2. 同类操作复用预计超过 3 次，必须优先沉淀成参数化脚本；频繁 GUI 点击优先替换为稳定 API / CLI / Playwright 的等待条件，禁止硬编码屏幕坐标。
3. 每个脚本记录目的、输入/输出、前置条件、幂等性、超时、失败分类、回滚方案、成功判据与实测证据。
4. 有副作用的提交先查询唯一任务 ID 和目标状态。超时不得无脑重试；先查结果，确认未执行后再重试。
5. 复用脚本应支持 check/dry-run（适用时）；涉及不可逆修改须备份、申请最小范围锁并获得必要授权。
6. 新技能录入技能索引.json，必须通过 `node 复用管理器.js check` 和真实业务测试后才标记 verified。
7. 多 AI 禁止覆盖持锁资源，脚本发布应保留版本、变更记录、回退路径、操作日志。
8. 云端 GitHub 仅备份脱敏的通用代码、规范与样例；禁止上传 Cookie、token、密码、用户草稿、个人文件、内部 URL、部署配置、访问密钥。
9. 本地目录是运行真源，云端只作安全副本；上传前检查敏感信息及云端仓库可见性，不能把上传成功当作本地脚本运行通过。
10. 不因复用规则而重复建设现有共享组件或打断其他 Agent。

## 标准验收
静态检查通过 + 真实输入执行通过 + 失败路径经过验证 + 执行记录有证据 + GitHub 备份可读取。
