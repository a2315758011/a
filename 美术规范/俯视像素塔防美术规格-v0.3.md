# V0.3｜以真实《兽人领地》为玩法参考的俯视像素美术规格
状态：设计候选 / 未到G0正式通过。参考事实：https://www.taptap.cn/app/714518；https://store.steampowered.com/app/3116120/_Orcdom/?l=schinese 。可见战斗截图：https://img-tc.tapimg.com/market/images/c0c3ce84262295a82dc9cd2463104423.png/_tap_screenshot.jpg 。

## 纠偏原因
原V0.1曾将游戏视角暂定为斜45°卡通机械塔、资源256×256高清源图。现已确认对标是 **正俯视2D、原生像素画、自由摆塔、兽人四面进攻、保护中央水晶**。继续按V0.1画塔会成为四不像，因此暂停V0.1/V0.2美术量产，技术ID/主核生命规则保留，外观与源画布由本V0.3更新。

## 像素体系（需结合真实局内截图/移动测试冻结）
| 不同尺寸层级 | 候选值 | 作用 |
|---|---|---|
| 游戏输出 | 1080×1920 | 抖音直播竖屏输出，不是单塔贴图大小 |
| 原生玩法预览画布 | 540×960 | 原生像素布局，输出至1080×1920应整数×2、nearest过滤 |
| 地表基础瓦片 | 32×32原生像素 | 草地、石砖、悬崖等独立Tile；不能附着在炮塔/水晶 |
| 普通炮塔动作画布 | 64×64原生像素，主体小于画布 | 每种每级固定对齐、锚点(32,56)（需叠图验收） |
| 炮塔局内可见宽度 | 1080输出约44–72px候选 | 主要取决于镜头缩放/同屏数量；64×64源画布不等于物体非透明宽64 |
| 被保护主水晶 | 96×96原生像素画布 | 只用于主核心，有专门底座、受击与破碎帧；输出可见高度约112–160px |
| 普通兽人 | 32×32原生像素画布 | 真实walk/hit/death多帧，随镜头采样整数缩放 |
| Boss | 64×64原生像素画布 | 可高于普通怪，但仍不超过主核重要性 |
| 运行时图集 | 1024或2048方图 | 紧密Trim及边距，但保留像素帧锚点和Atlas原始源坐标 |

⚠ 官方512×512场景截图无法反推原作贴图的真实源像素；上述全部是**本项目独立生产建议值**，不是声称原作采用32/64px。任何素材如使用AI绘画须对齐像素格，不能仅对高清画二次缩小后贴像素滤镜。

## 主视觉区分
- 中央**城防能量水晶**：发光青蓝多面晶体，在一个小型石/金属底座上，始终唯一、可见公共HP，是全体观众的共同被保护物；不攻击/不受礼物升塔事件驱动。
- 连珠速射塔：黄色金属小机匣，两个短枪管，弹丸向兽人射击。
- 熔芯重炮塔：红铜金属粗炮口，慢速炸弹，范围爆炸。
- 寒霜喷射塔：矮胖青蓝金属冷凝喷嘴、冷媒罐、机械线圈，发出冰雾。**不是一座尖晶体**，不能让用户分不清“枪”与“要保护的水晶”。
- 像素基础笔触：1px原生边线、有限色数、整数坐标和纹理点阵；独立前景对象全部Alpha真实透明，地表只在独立地图Tiles中出现。
- 观众昵称与等级是单独UI/Text组件；地图随时可替换草地/石板而不用重抠塔/核心。

## 玩法结构/镜头
首张玩法图必须是接近局内俯视图而非广告海报；正中主水晶，周边自由摆放塔，四边兽潮从四周汇聚中心，图上能读懂“塔在保护什么”和核心HP；完整地图可以带场景和地板，但**不能从总览图裁炮塔精灵作为正式资源**。考虑直播昵称遮挡、Boss显著性、中央聚焦和动态技能UI，优先展示战斗场地。

## 帧动画候选
- 塔：idle 4–6帧、attack 6–8帧、upgrade 8–10帧；每种攻击炮口/弹道挂点固定；序列帧真实变化且不越级切错。
- 兽人：walk 6–8帧、attack 6–8帧、hit 3–4帧、death 6–10帧，多方向转向可经独立方向帧或合法镜像。
- 主水晶：idle 6–8帧、hit 4–6帧、crack 6–8帧、destroy 10–12帧；HP由规则决定，不重复计伤。
- 不用静态图复制多张冒充动作，保持Approved Master与所有分层/动画形态一致。
