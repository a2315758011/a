# 透明资产强制验收（炮塔、敌人、弹道、特效）
这里的“透明”是PNG真实Alpha通道，不是纯白色。纯白仅用于审核参考图，不准作为Runtime贴图背景。

## 机器门禁
先执行（当前工作站已确认Python和Pillow可用）：
```powershell
python "美术规范\透明资源验收.py" --self-test
python "美术规范\透明资源验收.py" "游戏美术\炮塔\连珠速射塔\一等级\待机\待机_0001.png" --width 256 --height 256
```
出现PASS_MACHINE_ONLY只代表格式、Alpha、尺寸和2px空边通过；并不代表正式可用。
脚本会拒绝RGB、全不透明、全透明、透明面积不足、画布边缘非透明以及尺寸不符。
对128px底座使用 --width 128 --height 128，对不同尺寸资源显式声明。不得靠修改PNG宽高欺骗检查。

## 人工 + 引擎门禁（不可用机器PASS替代）
1. 源图片含有绿色地板、草坪、道路、浅色背景、条状阴影底片、海报文字 → 直接FAIL。允许机械底座自身的合法彩色材料，地块永远独立。
2. 同一真正RGBA资产叠在纯白、深灰、棋盘、草地、石砖测试场景，不出现方形边界/绿边/白边/错误接地。
3. 隐藏机械底座时，塔身仍可作为独立精灵调整位置；关卡换地板不要求重抠或重绘塔图。
4. 同塔5等级同锚点同相机，逐帧红线叠图看落地漂移；不能突然弹跳或视角变化。
5. 64px/48px远景仍能区分三塔；1080p/720p录屏检查压缩之后的读图。
6. 动画不是多个相同PNG；不同动作的帧有实际像素变化，攻击特效与真正逻辑发弹同步。
7. 源图和同版本运行证据、manifest hash、许可证、Atlas导入参数同时记录，未全部通过不得promote到正式游戏包。
