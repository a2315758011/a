# 剧本转分镜总导演指令 V4.0｜候选版（与 V2.8.3 基础规则联读）

> 版本基线：需要先完整读取仓库 main 的《剧本转分镜指令》V2.8.3，继续执行原有 SCG、source、资产权威、分镜 SVG 与交接状态机制；本文件扩展导演编排/事件时间门禁，不替代上述正文。当前仍为候选分支，main 未生效。日期：2026-10-26。
> 适用：AI 漫剧、动态漫画、2.5D、混合动画及经确认的真人商单。按项目媒介类型分别执行，不把同一手法硬套全部题材。
> 性能目标：让观众看清事件、理解因果、感受选择和代价，再谈镜头技巧和生成稳定。白模预演不要求脸部表情。

## 0. 唯一权限与版本入口
- 开工先锁定“原始剧本/用户已确认设定/官方参考资产/时长和画幅/目标模型能力/产出媒介”，记录来源路径、版本、哈希。禁止自创关键剧情和对白。
- 教师在线正式入口是 GitHub `a2315758011/a` 的 `main/分镜规则清单.json` 与 required 全文。每轮正式工作先核对远程清单；本候选不能假称线上生效。离线可以全文执行但标“未核验最新”。
- 现有角色、场景和道具使用同一实体标识。没有资产或模型能力档案时可做可读导演稿，不能称生成就绪。
- 执行流程：事实映射→戏剧设计→空间调度→动作时间与并行图→镜头与声音→导演预演→模型编译→独立审片→定向修复→交付；不得倒序。

## 1. 拍之前先回答“这场戏为何值得看”
每场只写一张导演场记卡，包含：
1. 主角此刻要什么（可观察的行动目标，不是抽象情感）；
2. 谁/什么挡住目标、反派为什么坚持（敌方有可理解动机不等于必须洗白）；
3. 角色先用什么策略，遭遇什么反制后被迫改变；
4. 什么信息在何时揭露：观众已知、角色已知、角色误以为已知应分列；
5. 本场至少一个不可撤销的选择/损失或有意保留的悬念；
6. 入场的权力/危险/情感位置，与离场时相比究竟改变了什么。
若整场只有“很多攻击、许多漂亮特效”但没有策略或代价变化，不得只添加运镜装饰，先重排真实剧情信息的呈现顺序；不新增剧本事实。

## 2. 每镜的唯一主任务与观众注意力
每镜只能有一个首要视觉信息任务（可以自然附带声音/背景动作）。写：
- 【观众先看见】视觉焦点的实体、位置与可见性；
- 【随后发生】可见动作的关键变化；
- 【此镜后观众知道/误判/感受】相对于入镜前新增什么；
- 【为何必须此景别/机位】以及不拍这镜会损失什么；
- 【切镜触发】动作完成、反应、声音桥、空间重新建立、视线交接或悬念节奏。
同一镜不能既强制看清头部口型又要求看清框外腰下操作；必须在实际画幅与机位实现可见性。镜头运动要给起点/终点/可见焦点，而非泛称“推拉摇移大全”。冗余镜头不因炫技保留，必要情绪反应也不因没有新对白被误删。

## 3. 导演 Blocking：把文字落实为空间动作
- 场景图 GEO：入口/出口/障碍/可用接触面/高低差/世界坐标与银幕轴线。只追踪剧情有关的对象。
- 演员 Blocking：每名关键角色的起点、目的地、朝向、视线、途经路径与障碍、身体重心、手/脚任务和结束位置。
- 摄影 Blocking：机位与焦距/景别、运动轨迹、观众视线顺序；机位移动不能替演员瞬移；跨轴要可见建立。
- 道具：唯一实例、载体/容器、所属、接触/释放、朝向、可见与可读、持久状态；出画不等于消失。
- 动作：准备→接近→接触→执行→完成→反应，只对剧情关键动作强制全链拍清；次要人群按“群体趋势＋1至3个锚点”处理，不强制逐人微编舞。
- 白模预演验收的核心是运镜＋走位＋动作能让不了解剧本的人看懂谁做了什么。白模不审脸部表情、妆发、口型或材质。

## 4. 时间可行性与动作依赖图（硬门禁）
先为每个关键事件建立事件表（可独立 JSON）；每项含 `event_id / actor_ids / resource_ids / prerequisites / start_range / completion_range / duration_min / duration_expected / visibility / consequence / uninterrupted`。
- **串行动作**：同一只手“抓物→抬起→插入”不能重叠；单角色要求同时握双手闸门、双手舞剑即冲突。串行最短总时长不可超过镜头窗口。
- **并行动作**：不同演员可同时行动，同演员可说话伴随简单动作；并行必须有真实资源、机位、注意力及声学可行性，不把所有时长盲目相加，也不凭“同时”把冲突消掉。
- **跨镜连续**：持续持闸/倒计时/追踪/音乐相位是全局事件；明确真实起点、是否允许画外持续、谁在保持以及何时停止。若剧情要求持续30秒，最迟开工时间＝硬截止时刻−30秒；不得用宣称的开始时间替代画面实际触发时间。
- **群体人数**：`13人逐一核对`如要求画面逐一辨认，应逐一给时长或改成“领头核对＋队伍趋势＋终态人数凭证”并确保剧情授权；不能写3秒逐人完成13次清晰特写。任何动作时长为估计时必须标范围与验证方式，不冒充实测物理定律。
- **对白**：以实际朗读/语音样本估时，标明确语义停顿、说前反应和说后余波；不为赶秒数非自然加速。不能纯按中文字数断定精确时长。
- **时间调整优先级**：移到已有空窗/允许平行的时间→用切镜或声音桥合法省略非关键操作→调整镜头分配而保留集长→退回剧本冲突待核；不许通过道具瞬移、人员瞬移或虚构动作“已发生”来救时码。

## 5. 打斗与法术：战术可读性高于粒子数量
动作段至少标记：威胁来源→初始间距/掩体/站位→起手预兆→进攻向量→防守选择→命中/落点→身体/地形代价→攻守态势反转/新策略。
- 战斗节奏必须有“试探/压制/失手/临机改变/代价/反击或撤离”中的真实变化；不强制每一招都包含完整六拍。
- 每击标注能量源、轨迹、碰撞对象、遮挡、受力方向、击中后物理状态和恢复门槛；特效不能遮住改变局势的接触点。特效量大可以，但“满天飞”的光只能放大战术信息，不能取代位置关系。
- 主角/敌人能力、距离、冷却、耗材、受伤状态随镜头继承；敌方有战术适应而非机械轮流送死。
- 多人近距精细互动与强运镜、强特效叠加时必须定义降级镜头方案（保留完整因果链而非删除戏剧）。
- 设三种节拍节奏：动作发力快、因果结果可辨、重大选择可停顿；不能所有镜头高频摇晃。

## 6. 情绪戏不只写“悲伤、愤怒、停顿”
为关键情感拐点创建【触发事实→最初抑制→对抗动作/潜台词→不可逆选择→他者反应→情绪余波】链；并标观众需知道的铺垫和最终回收。
- 人物情绪必须与已看到的证据和失去的具体对象相联；沉默、距离变化、重复动作中断、停手或握力变化往往比喊口号更有力量。
- 同情反派不等于替其错误开脱；观众应同时理解其错误动机与选择的伤害。
- 关键台词安排对话对象、说前动机、说中行为、听者反应和结束后的静默空间；与配音、环境声、BGM的进入/退出同步。
- 观众情绪不是按指令词“感人”验收；需真实观看样片，区分“信息理解”与“被打动”。白模阶段不要求表情，只审动作选择与镜头表达。

## 7. 转场与信息分配
- 建立三层信息轨迹：观众知道的、角色知道的、镜头允许展示的；禁止无意剧透和无原因反转。
- 景别变化由认知目的和动作结果决定，不做固定秒数换景。
- 长镜头负责连续动作或压迫；切镜负责信息对照、反应和时间省略。若从远景直接切特写影响空间理解，补方向/空间锚点或改机位。
- 各集开头给具体冲突，各集结束形成明确悬念/代价/未完成选择；前后集剧情账本可追踪。

## 8. 资产与生成模型编译（绝不把导演稿直接等同模型提示词）
分层交付：
A. **导演分镜稿**：模型无关，镜头意图、台词、机位、走位、关键动作、完整事件、声音、时码。
B. **可视预演**：关键帧/故事板、必要 SVG 构图和白模运镜走位，检查空间与动作；按平台或需求产出静态漫画时另走漫画分格与阅读顺序。
C. **生成编译单**：T2V/I2V/续写/编辑的模型、版本、模式、真实能力和素材引用；按自然动作闭合点生成 GEN，不能盲目一个镜头一个提交。每 GEN 写唯一生成提交ID、参考资产版本、开始/目标结束状态、风险及回退。
D. **Take与剪辑证据**：真实视频长度、有效 in/out、通过 Take 的实测出口状态、音画相位与镜头位置。下一 GEN 只能从真实合格 Take 尾态继承。
不伪造资产、视频、配音、模型单次时长、参考图/骨骼控制能力。精确字幕和文字优先后期。用户首次审稿若项目线上入口要求 SVG，应给每镜真实构图 SVG，而非只写“已画”。

## 9. 反证机制和提交门禁
在首稿提交前，强制找出三种最可能翻车情况：时间不够、空间/物体物理不可能、观众看不懂或不感动；任一命中先改，不加形容词。
主指令必须显式调用与自己同版的《剧本转分镜自检指令 V4.0》，禁止误调用 V3.0。
内部质检与用户阅读稿分离；输出清晰、紧凑、可拍的镜头，后台才保留 source_id/SCG/事件拓扑/JSON。
四级证据：T文本审查、K画面或白模、V实际视频、E剪辑成片，各自独立。缺一项不准宣称该项通过。
主要动作、持续事件、角色状态 P0/P1 必须归零方可称“该阶段通过”；审稿评分只是辅助，不能因平均高分掩盖物理矛盾。
正式文件交付还需：完整可修改正文、审查与修复记录、尚未验证项、版本来源与工程备份。不得把候选V4当作已生效在线main。

## 10. 可复制的镜头输出模版（示例字段，不要求堆字）
【镜头ID｜集内与全局时间｜主任务｜景别与构图】
【进入状态】人物/关键物体的必要初态与观众已知信息
【画面动作】先看到什么→实际动作过程→可见后果；主要视觉焦点必须明确
【演员】目标/策略/反应/声画节拍（白模只写走位与动作）
【摄影】机位侧、起止画面、轨迹、切镜条件及理由
【声音】原文对白说话人、SFX、环境声与允许的配乐/留白
【退出状态】下一镜必须继承的可观察事实
【备选方案】同剧情更易拍的替代镜头，不改变核心因果
详细JSON事件表和时间图留给执行器或审核报告，不得污染人看的正文。


## 12. 导演决策与动作时间补充细则

## 适用边界
本节是 V4.0 主规则的具体执行细则。保留原剧本事实锁、资产权威、SCG及中文文本输出规范；导演可读稿与机器账本分离。遇到冲突，记录来源和版本，禁止暗中覆盖原剧本事实。

## 总负责人的第一原则
**让观众不读分镜文字，也能通过角色目标、行动、阻碍、后果、镜头信息和声音判断故事发生了什么。**对白不是剧情自动成立的证明，场景里有演员不是事件已发生的证明，白模画面能导出不是导演通过的证明。先求叙事证据完整，再求精致与特效。

## P0：五层决策优先级
- L1 剧情因果：每场必须有角色当下想要的结果、阻碍、具体尝试、意外信息、不可逆选择、代价；不得为了“电影感”新增原剧本没有的事实。
- L2 导演演员调度：冲突的空间发生在哪里？谁先知道？谁发现异常？观众按什么顺序得到信息？动机转折必须有能看到/听到的触发。
- L3 时空物理：人物、道具、声源、镜头起止位置；动作占用资源的时段和持续约束，不允许一个身体同一时刻承担互斥任务。
- L4 视听实现：每镜一项主要视觉证据，明示镜头任务、主视线、交互对象、机位、切点和出镜状态；声音拆分台词、音效、环境、音乐授权。
- L5 模型生成：已核验的模型能力、参考资产ID、白模/动作母本、GEN、真实Take、实际尾态。未知能力不能靠假设获得通过。

## 第一关：戏剧工程（不能用镜头表代替）
每场制成内部场卡：
1. 角色【想要】和失败代价；
2. 当前【错误信念/未知信息】；
3. 【迫使行动的事件】→【尝试】→【反制】；
4. 【事实/权力/情绪如何改变】；
5. 【不可撤回的决定和代价】；
6. 【观众新增知道什么】以及下一场的悬念。
没有事件因果或人物选择时，退回剧本诊断；可提出分镜内重排的改造，但不可擅自增删剧情事件或原对白。

## 第二关：单镜视觉证据契约
读者正文保持人能读懂、简洁，不暴露后台字段。内部对每镜必须有：
- “观众原本相信X/看不到Y → 看见什么直接证据 → 观众现在知道Z”；如果无改变，说明其具体铺垫/反应/空间功能；
- **画面先后**：第一个抓眼对象→动作主体→结果物件或受影响者→情绪反应；
- **物理过程**：初始位置和朝向→启动/发力→接触→受力/状态更新→完成后是否保持；
- **摄影机**：所在轴线一侧、画幅景别、相机起止位置、镜头动作的戏剧理由、最终需要保留的锚点；
- **切点**：动作稳态/声音桥/视觉匹配/情绪突变或因果揭示，不许凭空“下一镜人物已拿稳”；
- **显性/隐性状态分离**：镜头外的状态由后台账本继承，不能为了把无关物件拍清而破坏画面焦点。

## 第三关：动作与对白的时间资源图（硬门禁）
每个关键事件内部记录 actor_id、task、start、end、required_predecessor、required_resource（左右手、脚、身体、机位焦点、道具/空间）、hold_until、can_overlap、visible_evidence。
1. 只有不互斥且相同叙事意图允许并行的任务才能重叠；先拿稳才能松手；先插接完成才能亮屏；先握闸且持续至终点才算满足“持续按住30秒”。
2. 不能只做镜头起止和时长之和；校验开始时间、完成时间、持续占用的中断、跨镜头继承和跨场音桥。
3. 台词按中文**真实合成/演员试读**测声音长度和呼吸/停顿；未测不可把英文词/分钟速率套用到中文台词。文本初筛只标风险。
4. 超预算时按顺序：去无叙事作用的步骤→换景别使关键过程并行可见→声音桥→同场切镜→调时长与相邻镜节奏。不可删除必要因果、伪造瞬间完成或假设无声高速表演。
5. “全部发生”不等于“逐一可见”：群像采用群体趋势、关键锚点人物、成立的时间蒙太奇与可信人数证据；若剧本强制逐个呈现则必须给足可演时长。
6. 检出明确资源冲突：P0 FAIL；物理最短时长无实测但明显可疑：NEEDS_REVIEW，不许一笔带过判PASS。

## 第四关：情绪导演与不可逆选择
每个重大情绪事件须证明：人物原信念→触发事实→首先试图压抑/否认→非语言身体信号→选择改变→代价持续。不能只写“痛苦、感动、愤怒”，更不能用喊叫、配乐、眼泪自动代替动机。白模阶段不检查脸部微表情；仅验观众能否从走位、动作和机位理解目标变化。正式角色动画再验神态、台词、音色与呼吸。

## 第五关：战斗编舞
每场打斗至少设计一个“战术问题”，每次交锋做表：
敌我方位/有效距离→谁先发动、为什么→攻击轨迹与速度趋势→应对选择（挡/闪/骗/绕/借环境）→实际接触与受力→损伤/空间后果→战况或目标改变。
持续升级必须出于位置、资源、伤势、知识或心理变化；不得仅把剑气数量变多。复杂斗法可拆**动作母本、角色层、术法层、环境破坏层、合成层**；白模先证明胜负空间、命中和接触，特效后补，不让特效遮住谁击中了谁。

## 第六关：白模/分镜动态验证
按风险选择，不强制所有静态对话建立3D：
A 静态单人反应：构图/角色图检查；B 简单走位：2D 动作路径或关键帧；C 双人接触/道具交接/复杂走位：白模完整动作过渡；D 打斗/破坏/大量特效：动作母本+可独立复核的接触帧+特效层。
观看预演时**遮住文字**，对每镜问：谁做了什么、接触了什么、哪个物体变化、角色为何改变行动？答不出就不通过。白模不要求面部表情、真实服装材质。
SVG只代表构图草图，不得冒充真实预演；有要求逐镜SVG的在线规则时如实交付但仍做相应动态验证。

## 第七关：生成、独立审片和回退
- 对每镜以场卡、状态卡、已锁资产、机位/预演母本编译T2V/I2V/Continuation/Edit，并给出降低风险的B方案。
- 文本校验T → 空间/动作预演P → 模型Take V → 剪辑成片E。上一层PASS不推定下一层PASS。
- 真实Take必须检查开场、接触点、转折点、首尾状态、声音、镜头焦点；找出第一个可观察失败时刻。保留任务ID、实际时长和可用素材区间，不盲目重复提交。
- 独立审片分两条：技术一致性与**观众不看脚本能否叙述事件**。关键镜头随机不看台词播放，审片者描述动作对象和结果，与预设叙事目的核对；评审不同意见说明原因并重测。
- 修复只改真正失效的镜头及其影响后继；两次同根因不收敛时改动作结构、模型模式或白模母本，不继续堆砌否定词。

## 分镜阅读稿最小格式（每镜）
【镜头ID｜本集时间｜真实剧情时长｜景别｜视觉目的】
【入镜时】人物与关键物件的可见关系
【动作事件】起手→交互/接触→结果；哪些动作同镜并发/哪些只靠剪辑省略
【观众理解】这一镜应被理解的新增事实/关系
【表演】触发→动机/犹豫→身体反应；无表情白模阶段只写动作
【摄影机】位置、起止、运动目的、切点
【声音】原对白、起止相位、合法SFX/环境、BGM授权
【出镜时】影响下镜的关键状态（用户阅读稿简述）
【执行方式】可行模式与高风险降级；未绑定资产明示待确认

## 强制试例：已有《病友仙门》缺陷不得再次通过
- E3-05/E3-06：目标03:30–04:00持续压闸，动作实际03:34后才开始 → P0；必须修正明确开闸起点或重新设计叙事时间，不得悄悄将30秒缩为22/26秒。
- S068 3秒让13病患逐人入舱、核对铜牌且轮椅过门 → NEEDS_REVIEW/局部P1；须区分集体趋势/关键锚点/可展示清点与全部真实登舱耗时，仍保留18人事实。
- S056 一秒“先稳息约1秒，再触剑” → 串行理解为时间不可容纳；改为一秒内稳息、下一镜接触，或测出可并行版本，不偷改能力规则。
- 保留既有书包手机、单椅、道具交接、越轴、群演去重回归；但必须新增以上时间冲突、情绪反证及无脚本观看测试。

## 版本/交付规则
主规则、审核规则、源SHA、离线包SHA必须列入统一manifest；离线包若与main不符则标注历史快照。支持工具时实际跑校验并记录结果；不支持时只声明人工审查。正式发布前必须完成同一74镜剧本A/B比较与真实预演复检；如果预演/资产/模型不可用，必须标未验证并保持候选状态，不得将文本通过冒充成片通过。



## V4.1-RC1 增量：电影感镜头的可执行编译与验证（2026-10-26）
> 本节是原 V4 规则的增量，不替代 V2.8.3 基础规则、SCG、导演 Blocking、事件时间图或自检门禁。设计师言炎原视频《12种镜头》尚未逐帧取证，不能将本节归于作者原话，亦不能捏造12项清单。

### 一、分离镜头语言与模型生成指令
每个生产用 GEN 必须提供可追溯的机器编译单：`scene_id / shot_ids / gen_id / source_id / asset_ids / asset_versions / start_frame / expected_end_state / aspect_ratio / duration_requested / model_version / generation_mode / ability_evidence / subject_action / camera_motion / visual_focus / time_beats / fallback / output_take_id`。导演可读稿仍遵循原 V4 最小格式，不在正文堆叠 JSON。

摄影视觉参数分开标注：景别、机位高度、视线方向、构图焦点、机位实体轨迹、镜头角运动、焦距变化和起止画面。推轨（dolly）不等同于变焦（zoom），摇摄（pan）不等同于横移（truck），环绕必须明确主体和空间锚点。固定机位明确写 locked/static，不用“电影感”之类修饰词代替可观察运动。先确定一个主要镜头运动；复合运动仅在目标模型当前模式有官方说明或实测能力证据时使用。

### 二、镜头动作与时间控制
每个 GEN 只包含时间上可实现的主要动作及其起止、关键时点和可见结果。图生视频优先说明首帧之后的主体运动、镜头运动和场景变化，避免用首帧外观文字盖过运动指令。长动作按自然完成点拆分为多镜，剪辑接口写明真实承接状态、方向、视线和声音桥；不能用剪辑假装动作物理过程已发生。

### 三、双人近景与连续性
在双人近景记录左/右角色 ID、前后遮挡、焦点角色、目光目标、摄像机轴线侧、镜头进出状态。反打、合法越轴或演员移动造成的画面左右变化，应具备明确的可见过渡、建立镜头或有意剪辑说明。不可简单将“画面左右交换”等同于错误，也不可无来源填充缺失字段。

### 四、修仙打斗与阵法分层
关键击打建立：起手/蓄力 → 攻击向量 → 接触或有效闪避 → 受力方向 → 具体伤害/地形后果 → 可继承的终态。阵法记录锚定面、施法者、阵纹触发次序、受影响对象及消散/恢复条件。效果层区分背景、地面阵纹、角色/法器、命中能量、前景粒子和后期合成；确保决定胜负的接触点与人物状态在镜头中可辨。复杂打斗需有降级镜头方案而非盲目堆特效。

### 五、能力证据、Take 回写和失败恢复
对每个 model/version/mode 的首尾帧、单运镜、复合运镜、参考资产、时长支持分别标记 OFFICIAL / TESTED_PASS / TESTED_FAIL / UNKNOWN，并记录官方链接或测试 Take 路径、日期、参数。先固定人物、场景、首帧和模型做 A 静机/B 单运镜/C 复合运镜对照；记录重试、有效可剪时长、人物一致、轨迹偏差和成本，不以少数样例宣称稳定。
每次提交唯一 taskId，保存参数与真实素材、审片结论、in/out、下一镜承接的真实尾态。失败按身份、空间/越轴、动作接触、时间、特效遮挡、模型不支持分别归因；一次只改一个主要变量。已有提交先核查真实任务状态，禁止盲目重提。

### 六、程序与成片分级门禁
程序可用时，分别执行既有 SCG、V4 事件时长和镜头连续性校验；缺少必要机位/角色/资产/动作字段时状态为 UNVERIFIABLE，而非 PASS；检测明确违规则 FAIL。只在全部必需校验明确通过时给出对应程序级 PASS。
保持 T 文字、P 动态预演、K 关键帧、V 生成视频、E 剪辑成片独立验收：静态测试通过不等于视频通过。未接入新校验器时记录“镜头专项未执行”，不可声称全量系统生效。
