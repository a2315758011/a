# 分镜导演 V4.0｜按用途分类

> 当前是 V4 候选版本，尚未通过成片级验收，不能视为已在 main 正式发布。

| 顺序 | 分类 | 入口 | 作用 |
|---|---|---|---|
| 01 | 一键入口 | [一键总调度指令](./01_一键入口/一键总调度指令-V4.md) | 新手直接复制启动 |
| 02 | 导演创作 | [剧本转分镜指令](./02_导演创作/剧本转分镜指令-V4.md) | 戏剧因果、运镜、走位、打斗、事件时间 |
| 03 | 独立质检 | [分镜自检指令](./03_独立质检/剧本转分镜自检指令-V4.md) | P0/P1、连续性、可视预演与验收 |
| 04 | 程序校验 | [事件时长校验器](./04_程序校验/分镜事件时长校验器-V4.js) | 校验结构化事件数据 |
| 05 | 测试样例 | [时间回归样例](./05_测试样例/分镜时间回归样例-V4.json) | 程序正反例测试 |

## 最简单用法

上传剧本并输入 **开始分镜**。如果剧本已在当前对话，则直接输入。只审不改输入 **只审核分镜**；初稿后希望暂停输入 **逐阶段审核**。

## 权威规则和安装包

- 在线按仓库根目录 [分镜规则清单](../分镜规则清单.json) 加载两份基础规则 + 两份 V4 规则，不得只加载 V4。
- 需在无 GitHub 环境使用时，上传根目录的 [学员分镜双规则完整版 V4.0](../学员分镜双规则完整版-V4.0.md)。
- 可安装的 Agent 技能源目录在 [skills/storyboard-director-cn](../skills/storyboard-director-cn)。该包的 `SOURCE_LOCK.json` 约束 Git blob SHA。
- 旧 V2.8.1 ZIP 仅为历史快照，不是 V4 安装包。
- 程序校验只检查结构化事件，不代替白模、视频 Take 和成片级检验。

## 测试命令

```bash
node "分镜导演V4/04_程序校验/分镜事件时长校验器-V4.js" "分镜导演V4/05_测试样例/分镜时间回归样例-V4.json"
```
