# 分镜导演 V4.0 使用说明

1. 最简单的用法：上传原剧本，在对话里发“开始分镜”。
2. 若只审不改，发“只审核分镜”；若先看初稿，发“逐阶段审核”。
3. 在线 AI 必须读取根目录两份基础规则和本目录两份 V4 规则；离线 AI 上传“学员分镜双规则完整版-V4.0.md”。
4. V4 校验器只验证结构化事件账本，不能自动理解任意中文剧本，不能替代白模/视频实测。
5. 当前发行是 V4.0 layered：保留完整 V2.8.3 基础规则并叠加 V4 导演与验收层。旧 V2.8.1 ZIP 是旧快照，不得冒称 V4。
6. GitHub 合并前本目录为候选版本；只有 main 分支清单列入 required 后才是在线正式规则。
