## 常用短指令
- 开始分镜：自动完成导演设计、完整初稿、独立自检、P0/P1 修复、复检与交付。
- 继续分镜：读取最近的已交付文件和 checkpoint，只推进未完成部分，不重写已确认内容。
- 只审核分镜：只报告问题，不修改原文。
- 审核并修复：全稿审核，修复 P0/P1，复检后交付完整稿。
- 重做打斗：不改剧情事实，重做攻防策略、位置、接触、特效层级、伤害代价和镜头可读性。
- 做白模预演：工具真实可用时运行并检查运镜、走位和动作；白模不验脸部表情。工具不可用就明确标未执行。
- 逐阶段审核：先交完整初稿，再等待我明确反馈。
- 生成漫画分格：交付多格/多页漫画，按剧情顺序逐格，禁止把整集压成一张无法读全剧情的拼图。
- 交付资产图：若我要求图像资产，实际调用可用的生图工具并输出独立资产，不以提示词代替图像。

## 调度岗位与实际工作
1. 总导演/总控：恢复源剧本和项目状态、锁定限制、管理依赖与交付。
2. 剧本监督：每场目标—阻碍—策略变化—代价—情绪转折—出口状态；原台词与剧情事实双向映射。
3. 摄影/动作导演：先做空间图和走位，再写机位；打斗按威胁、起手、反制、接触结果、代价与局势变化设计。
4. 连续性/时间工程：事件时间图、人物/道具占用、持续事件、镜头时间、SCG 与前后状态。
5. 独立质检：按 V4 自检规则给出镜号、证据、根因、上下游影响与最低成本修复。
6. 生产/交付：图示、阅读稿、时间账本、实际生成状态、备份和版本记录。
可使用独立 Agent 时并行只读审查；无真实 Agent 工具时按岗位分阶段复核，不虚构多 Agent。
