# 剧本转分镜自检指令 V4.0｜候选版（与 V4.0 主指令一一对应）

> 审核必须独立于写稿自我肯定：有独立审片者则盲审；无则注明内部自检。先实证、后结论。此候选并未自动接管 GitHub main 的 V2.8 规则。

## 0. 审核素材
原剧本与已确认版本、当轮导演稿、最新资产约束、模型能力档案、世界/事件状态账本、实际关键帧与视频Take（如果已产生）。无来源不可推断有明确效果。先记录适用媒介：白模预演／漫画分格／视频分镜／真人实拍。

## 1. 八道独立门禁（顺序不可省）
**G0 来源与真伪（P0）**：源剧情事实↔镜头双向映射，重要人物/台词/选择有原始依据；未经许可新增角色、群体欢呼、重大因果、剪辑凭空引出新信息都不行。
**G1 戏剧因果（P0/P1）**：每场愿望—阻碍—策略—反制—代价—转折能被具体镜头观察；观众信息轨迹和角色知识不矛盾；高潮是否有铺垫、牺牲是否有代价；缺少叙事信息判 P0，情绪薄弱判 P1。
**G2 动作和时间（P0）**：分“串行依赖/合法并行/画外可延续”三类，真实可见触发时间必须与“持续N秒直至截止”一致，不能用标题或备注明确“从某秒开始”代替在画面发生。每个动作至少给最低可行时长依据（实拍/配音/合理范围），无法估测留待预演，而非伪造精确结论。
**G3 空间调度和拍摄（P0/P1）**：场景拓扑、摄影轴线、起止机位、动作方向、人物路径、真实可见性与遮挡、唯一道具、接触/受力/接续状态。关键动作看不到或不可能判 P0。白模不检测微表情/口型。
**G4 战术和动作美学（P1）**：每场冲突是否有威胁、策略与反策略、能量轨迹、命中代价、新态势；是否光效盖接触、无限技能、角色被动轮流受击；快慢节拍是否有目的。不给“特效多”额外分。
**G5 情绪和表演（P1）**：情绪由事实触发、演出抑制和崩溃、听者反应与余波；对白不能机械同时承担大量手部操作。对白依真实朗读时长复核；白模只查动作和走位剧情感。
**G6 模型与资产（P0阻断“生成就绪”）**：模型名称版本/真实上限/支持模式/参考资产ID/状态变体与生成段复杂度，未知即“仅导演稿”，不得宣称已可生成。
**G7 样片和声音（实际门禁）**：T文字→K关键帧/预演→V真实Take→E最终剪辑，分别留文件/时码/成功证据。白模剧情可辨认优先；视频口型、人物一致、物理接触、音画相位和剪辑体验只能在真实成品判断。

## 2. P0/P1/P2 定级
P0：时间数学不可行、持续操作起点错误、同一肢体执行互斥动作、因果事件缺失、关键人物/道具凭空瞬移、错误原对白、观众必需信息无法看到、生成模型硬上限确知但被超出。
P1：时间真实性高风险待预演、战斗无状态变化、情绪反应无可见铺垫、多人表演过载、无必要运镜、画面主次不清、构图/视线歧义。
P2：次要细节与表达冗余。禁止将P0降为P2来凑全通过。

## 3. 明确四条V3.2失败回归（必须真的用实例测）
**R-TIME-01：S068**，3秒完成13人逐一登船且逐人铜牌核对，若要求观众逐一看清全流程，动作时长/视觉信息严重不足。允许给出“只展群体趋势与总数凭证”的镜头改写提议，但必须说明其是镜头表现省略不是物理完成被魔法加速。
**R-HELD-02：S064/S065/S066/S067**，称03:30—04:00连续按住30秒，但S066在03:34之后才第一次写双手扳住闸门。时间区间不允许宣称30秒真实执行；需调整镜头事件起点且修复上下游时码，不能用旁白补。
**R-REF-03：V3.2**主指令正文引用《自检指令V3.0》不符合实际配套V3.2，主/审版本引用必须一致。
**R-SHOT-04：S001/S002和带“道具特写转中景”镜头**，同一镜景别转变缺明确运动还是剪辑切点，审查时要求标独立切镜或摄影运动可实现机位。

## 4. 自检结果需要实测数据
问题记录：issue_id、源文件路径/行号、shot_ids、severity、观察到的矛盾、上游/下游影响、最小修复法、复检证据、剩余不确定性。
按资源画事件依赖图，时间计算基于物理动作触发/完成时间，显示最早可行完成与冲突裕量。估计值必须标风险，不可宣称数学证明全部表演可拍。
修改必须只影响有问题镜头及依赖范围；全局时间、倒计时、对白、重要道具、技能冷却、人物受伤史重新核对。不能改变用户没有授权改动的剧情事实。
“文本没有规则矛盾”“结构化JSON通过”“白模镜头剧情成立”“真实生成稳定”“成片可观赏”是5种不同结论。

## 5. 独立观众测试
至少回答：不看剧本能否辨认谁想做什么/阻碍是什么/动作真正发生了吗？能指出哪一个镜头改变了人物选择？战斗每一轮有没有位置、资源或风险变化？情绪的冲击来自具体损失还是空话？
有条件时盲看测试并记录错误理解的场景。没做不可假称观众理解率优秀。

## 6. 输出
A. 完整修订分镜（如果任务要求改稿）；B. 短问题表；C. T/K/V/E各阶段已验与未验；D. 主规则与自检版本/哈希；E. 未修复P0、P1清单；F. 下一步必需的实证。P0/P1!=0 不得通过当前阶段。
