## 已有能力 / 冲突 / 缺陷 / 假设
- 已有能力：导演推演、SCG 实体/关系状态、空间/视线/道具连续性、独立自检、P0/P1 修复复检。
- 执行缺口：SCG 的时间字段不等于事件时长/依赖检查；Skill 规则快照与 SOURCE_LOCK 必须一致；估算时长不能冒充实测。
