# AI 漫剧分镜导演升级候选 V4｜叙事、时长与预演证据门禁

> 状态：2026-10-26 候选；不代替既有规则与旧版；未经过真实模型生成及观众盲测，不得宣传商业成片质量已经提升。适用于剧本→镜头稿→白模预演→AI视频Take→剪辑的全链路。权威来源为原剧本及已经确认的角色、场景、道具设定。

## 一、为什么必须升级
现行 GitHub 根目录两份规则为 V2.8.3；在线分镜入口读取根目录；离线技能包及双规则完整版停留于 V2.8.1；Windows 本地另有 V3.2。三条路径并行使不同 Agent 易执行不同规则。V2.8.3已有 SVG 分镜和阶段审核要求，不能用本地 V3.2 简单覆盖。合并时保留已有内容而非做大段替换。

2026-10-24《病友仙门：炼气守星》V3.2 的文字结构校验为 3×80秒/74镜 PASS，但并非真实导演及时间可行性 PASS：
- S068 三秒内要求十三名病患逐一过门核对铜牌且处理轮椅；若要求将全部逐一展示，时长明显高风险。若用蒙太奇，须区分「剧情内全部完成」和「画面仅展示代表性片段」，标注真实省略范围；不能无依据将结构 PASS 写成动作可行 PASS。
- S065～S067 将段魁自全局03:30起连续压闸30秒视为已执行，但画面于03:34～03:38才完成锁槽与扳闸；同一个持续动作开始时间和动作前置条件冲突。必须修改实质时间线，不能仅调整描述。
- E1多处镜头已写运动，但缺少画面可观察证据的明确出口与失败判据。既有 DirectorDesk EP02 120秒技术导出通过而视觉叙事验收失败，说明结构正确不能替代真实预演。

## 二、必须新增的五个导演决策

### D1｜观众认知状态图
逐场输出「观众当前相信什么—角色当前相信什么—本场新增证据—观众判断何时转向—下一场悬念是什么」。每个镜头写可见证据、视线注意力先后、何时切镜、观众能否仅看画面理解变化。镜头有画面不等于事件被展示。

### D2｜戏剧压力曲线
逐场标主角目标、阻碍、策略试错、局势反转、失败代价、无法挽回的决定和情绪残响。高潮必须建立在前面事件的不可逆累积上。不得靠镜头震动、喊话、无端音乐替代情绪；不能因人物牺牲就自动给出感人高分。

### D3｜战斗动作节拍板
每场打斗至少写：距离/地形→意图与起手→对方读取/反制→命中或失手路径→受力与位移→能力/资源代价→新局势。复杂打斗用可视化平面站位与攻击矢量说明双方为什么能碰到彼此；维持招式数、角色能力、伤情和环境破坏的连续性。特效层依附于命中事件、能量来源及受力对象，不可用光效掩盖缺失的接触。追求高燃时增加可读的攻防策略变化，而不是无意义招式堆叠。

### D4｜镜头与声音的意图
每镜写主视觉对象、构图中心、起止机位、必要的摄影机运动、剪点由谁的动作/信息触发；主动考虑「固定镜是否更能讲清楚」。声音至少拆为对白/角色反应/动作拟音/环境声/配乐策略；白模阶段不以面部表情、配音自然度为评分项，完整成片才测试情绪声画表现。

### D5｜导演效果的可证伪条件
每个关键镜须至少给一个不用读剧本就能观察的通过条件，以及一个明确的失败征兆。比如“拾取成功”要求道具从桌面/地面转移至指定手且有连续接触，“拒绝杀戮”要求原持有燃符被可见地停用并产生下场行动后果。不满足则 FAIL，不能只写“动作完成”。

## 三、时间与并行动作门禁（P0）

1. 所有事件记录 episode / scene / shot / event 的稳定 ID，**剧情世界时间**、**镜头展示时间**、**模型请求时长**、**真实素材时长**分别记，不得混用。
2. 连续持续事件必须声明：start、end、保持状态/占用的角色部位或道具、触发前置条件、允许的并行事件、连续镜头的画内/画外证据。没有完成起手前置条件时，不能宣称“从更早时刻已连续保持”。
3. 对同一人占用的同一手、身体位置、道具，检查同时段是否要求两种互斥操作；可并行的对白、表情、行走也应受自然表演和模型复杂度约束。
4. 时间核算不可只检查镜头起止加起来等于总时长，还应检查：动作准备/接触/完成顺序、对白语速、镜内转场耗时、持续操作的开始条件、总持续时长与退出时机。
5. 群体行动要区分世界中实际完成的数量、画面明确展示的数量与蒙太奇省略。若剧本只需证实十三人全员登船，可先确立数量，画面展示少量关键核验+末态全员人数证据；若逐一展示为硬事实，必须重新分配时间，不能虚称三秒就拍完。
6. 时长下限只依据**实际动作排演/录音、可信分解计算或已确认生成能力测试**给出。缺数据标【时长未证实】，不发明统一的“每次握手1秒”等经验阈值。
7. 分镜承诺的事件只要画面或声音未能让观众确认，就标【叙事证据不足】；不是增加文字解释即可修复。

## 四、白模先行，但不要乱加门槛
对白模预演只验：运动路线、机位遮挡、人物朝向、关键物体接触、镜头切点、空间与剧情可辨认；不检查皮肤、面部情绪、嘴形、华丽特效。制作先拍最短关键动作样本，再整场，再整集；失败先修调度和碰撞关系，不反复微调焦距掩盖动作缺陷。复杂高风险镜头若当前工具不支持骨骼 IK、真实接触等，须标明【白模能力阻塞】，可改可见镜头与动作编排，不得谎称技术验收成功。

## 五、四类不同的判定
- **T 文本**：剧情覆盖、因果、时码、动作前后态、资源状态；原剧本完整方可判来源忠实。
- **P 预演**：真实导出并观察机位、走位、接触、叙事证据，按镜头记录问题。
- **V 生成 Take**：真实动作可见，角色/场景/道具/伤痕连续，音画同步，取到实际尾态；必要时逐帧看问题片段。
- **E 成片**：独立审看叙事连贯、冲突升级、情绪回报、音画剪辑，不能用 T/P/V 任一通过替代。
独立盲测仅在真实受试者独立观看和评分时成立；LLM 模拟审稿不等于外部观众测试。

## 六、最小反例集
- **V4-T01 P0**：锁闸须持续30秒自03:30，但03:34才扳住→开始时间违反动作前置。
- **V4-T02 P1/P0条件化**：十三人三秒内全员“逐个画面核验”→高风险；若坚持完整展示则时长不足阻断；若设计为省略镜头且全员末态证实则可修复放行。
- **V4-T03 P0**：手仍抓剑，下一镜无释放动作却换手操作闸门→资源互斥及握持跃迁。
- **V4-T04 P0**：脸、人物站位、镜头全正确，但钥匙未接触锁孔却自动开门→叙事事件证据失败。
- **V4-T05 P1**：只有攻击光效，没有起手、格挡/命中及受力后果→战斗叙事链不完整。
- **V4-T06 P1**：剧情号称角色已悲伤，却没有失去什么及不可逆行动选择→情绪因果不足。
- **V4-T07 合格**：十三人已由前镜确认，代表性登船动作后切完整舱内人数或可核对名册，承认蒙太奇省略，不虚构每人动作全被拍到。
- **V4-T08 分级**：白模没有表情属于不适用，不扣分；白模没有拾取的动作和机位可见证据属于失败。
- **V4-T09 FAIL-CLOSED**：只有文字规则和 SCG 12/12 回归，尚无真实全量 SCG 或视频→不得写本片已验证通过。

## 七、版本及发布门禁
主规则、独立自检规则、动态清单、自动调用入口、AGENTS 路由、SKILL.md、两个 skill references、SOURCE_LOCK、离线合并文档、发行 ZIP 须构成同一发布批次并哈希自洽。技能包不是动态在线规则；在完成重打包/重验之前，标记旧包“仅历史兼容”，不要误导学员使用最新版。提交前先用以上反例跑文本评审与必要程序校验，再用真实样片对照旧版；真实视觉验证没做则不冒称升级质量已实证提升。保留已验证的 SVG 逐镜示意和阶段审核，不用 V3.2 覆盖 V2.8.3。
