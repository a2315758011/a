# 价值洼地：从题材到“经验×媒介×阶段”矩阵 V1.0

日期：2026-10-26

## 一、模型正式升级

经过连续反证后，原问题：

> 什么人生经验没人表达？

已经不够精确。

现在的最小研究单位改为：

# 经验结构 × 媒介 × 目标人群 × 叙事阶段

例如：

“离婚后仍爱前任”

不能直接叫价值洼地。

因为：
- 音乐：高供给
- 小说：中高供给
- 短剧：中低供给
- 心理科普：中供给

而：

“已经设边界但仍觉得自己是坏女儿”

可能是：
- 心理科普：开始成熟
- 论坛/第一人称：高需求
- 音乐：低
- 小说：中
- 短剧：低

所以它更像：
**短剧/音乐中的后半程叙事机会，而不是全媒介空白。**

# 二、四维判断法

## 维度1：Experience
到底是哪一种底层经验？

不能用：
离婚 / 长女 / 原生家庭 / 职场。

要用：
- 道德残留
- 依恋残留
- 身份残留
- 结构残留
- 未来残留
- 退出权缺失
- 正确选择之丧
- 身份早封

## 维度2：Medium
在哪个媒介？

- 音乐
- 小说
- 短剧
- 情感短内容
- 播客
- 漫剧
- 游戏叙事

## 维度3：Audience
谁最容易认出自己？

不是人口标签优先，
而是心理角色：

- 长期可靠的人
- 习惯承担的人
- 已经完成边界建立的人
- 已经离婚但未完成情绪重建的人
- 从未真正探索人生方向的人

## 维度4：Stage
故事进行到哪一步？

- 觉察前
- 觉察
- 决定
- 行动
- 系统反弹
- 心理残留
- 身份重建
- 新关系

价值洼地经常发生在后四个阶段。

# 三、当前最有潜力的三个“完整机会句”

## O1
**对已经学会设边界的长女/成年子女，在短剧中讲“边界之后仍长期承受道德罪感与家庭系统反弹”。**

而不是：
“长女要学会拒绝。”

---

## O2
**对已经认识到讨好模式的人，在短剧/小说中讲“自由以后如何从零形成偏好和人生方向”。**

而不是：
“别再讨好别人。”

---

## O3
**对仍爱家人但不愿无限承担的人，在短剧/情感内容中讲“爱如何与退出权、责任上限共同存在”。**

而不是：
“不孝顺的人才不照顾父母”或“爱自己就该彻底离开”。

---

# 四、升级为“已验证价值洼地”的最低条件

必须同时满足：

1. **需求证据**
   多平台第一人称语料反复出现。

2. **供给差**
   同一媒介内，主流作品较少把该结构作为主线。

3. **对照**
   高表现、普通、失败样本都编码。

4. **表达实验**
   B版新解释不能只靠更长、更煽情。

5. **行为优势**
   至少一个关键目标指标稳定提升：
   - 自我叙述评论
   - 收藏
   - 分享
   - 追更
   - 长期角色关注
   - 付费

6. **跨样本复现**
   不能只靠单个爆款。

7. **反例**
   必须解释在哪些人群/媒介中不成立。

# 五、当前研究的真正产物

目标已经不是：

“价值洼地清单”。

而应该是：

# 《经验—媒介—阶段机会地图》

它可以回答：

- 一个经验在哪个媒介已饱和？
- 哪个媒介还没把它写透？
- 主流内容通常结束在哪里？
- 用户真正的问题从哪里开始？
- 哪种表达只是心理科普？
- 哪种结构可以成为人物长期弧线？
- 哪个机会应该做歌，哪个应该做短剧，哪个更适合小说？

这比“2026热门题材榜”更接近可持续内容研发系统。
