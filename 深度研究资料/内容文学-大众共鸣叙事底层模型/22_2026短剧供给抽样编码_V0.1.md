# 2026短剧供给抽样编码 V0.1

日期：2026-10-26  
平台：爱奇艺公开短剧页面  
目的：验证“觉醒/离开之后的后遗层”是否在当前短剧供给中相对不足。

> 重要：这是**便利抽样**，不是平台全量统计，也不能外推整个中国短剧市场。它的用途是检验“是否值得继续做系统抽样”。

---

# 一、抽样规则

纳入条件：

1. 2026短剧；
2. 爱奇艺公开页面可读取剧情简介；
3. 简介明确给出主角主要冲突和结局；
4. 主题与离婚、断亲、原生家庭、重新开始、觉醒有关。

本轮选12部。

编码重点不是“好不好看”，而是：

- 主角做出关键行动以后，故事把什么当作最终补偿？
- 是否把“正确行动后的心理残留”写成主要剧情？
- 是否存在R3道德残留、R4身份残留、R5系统残留、R6结构残留？

# 三、第一轮编码结果

**83%**

- 事业成功
- 财富上升
- 反派后悔/受罚
- 新伴侣

# 四、本轮不能得出的结论

不能说：

“83%的中国短剧都是这样。”

原因：

1. 只是爱奇艺；
2. 搜索主题本身偏离婚/断亲/觉醒；
3. 平台公开简介会压缩复杂剧情；
4. 简介不等于完整观看后的实际叙事结构；
5. 当前样本量只有12。

当前只能说：

> **在这一小批2026爱奇艺“离婚/断亲/觉醒”便利样本中，故事终点明显集中在外部补偿和快速新生，而把心理后遗层写成主要冲突的样本相对少。**

这足以支持：
扩大抽样值得做。

---

# 五、最关键的供需差

真实需求语料反复出现：

- 已经断联，仍内疚；
- 已经离婚，仍爱；
- 已经建立边界，家人仍反弹；
- 已经自由，仍不知道自己想要什么；
- 已经正确选择，仍哀悼另一种人生。

本轮12部短剧里，
这些几乎都不是故事主要终点。

因此当前最强假设变成：

# “外部补偿过剩，内部重建不足。”

不是没有“女性觉醒/男性逆袭”。

而是：

> **短剧很擅长证明主角当初离开是对的，却较少写主角离开以后如何继续成为一个完整的人。**

---

# 六、下一轮正式抽样要求

必须扩展到至少：

- 爱奇艺 30部
- 红果/抖音公开样本 30部（在合法公开可访问范围内）
- 其他平台 20部

并分层：
- 高热度
- 中热度
- 低热度/普通

每部编码：

1. 关键行动点
2. 结局补偿方式
3. R1—R7是否进入主线
4. 是否有外部反派
5. 是否有新爱情替代
6. 是否有事业/财富补偿
7. 是否允许主角长期矛盾
8. 是否以“圆满/新生/重生”结束

完成后才能讨论“短剧市场叙事断点”是否稳定存在。
