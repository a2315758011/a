# 首发吸引力与叙事满意度分离模型 V0.1

日期：2026-10-26

## 一、失败对照带来的关键问题

《昼以继夜2》：
- 被批剧情松散、流水账；
- 热度不如第一季；
- 但出品方称上线不到15天已接近回本。

《以爱为家3》：
- 首日热度6140万；
- 评分/收藏/点赞仍很漂亮；
- 同时大量评论批“散、拖、流水账、破产线没张力”。

这说明：

> **首发热度、商业回本、叙事满意度、长期IP信任不是同一个变量。**

---

# 二、四层内容结果

## A1 Acquisition｜获取

用户有没有点开。

受影响：
- IP
- 演员
- 标题
- 封面
- 宣发
- 前3秒
- 首集强钩子

## A2 Continuation｜继续观看

用户愿不愿意一直追。

更依赖：
- Hook
- Reward Density
- Reward Gap
- 核心问题是否持续推进

## A3 Satisfaction｜叙事满意

看完后是否觉得：

- 值得
- 不水
- 人物完整
- 结局合理
- 情绪被兑现

更依赖：
- Arc Continuity
- State Retention
- Reward Debt是否偿还

## A4 Franchise Trust｜系列信任

下一季是否还愿意第一时间进入。

它取决于：
- 前作满意度
- 角色弧线是否已耗尽
- 续作是否真的有新的核心问题
- 是否反复消费IP情怀

---

# 三、为什么高热不能证明叙事结构有效

强IP可以让：

A1很高。

但如果：
- RF高
- AC低
- State Retention低

A3可能下降。

于是出现：

> **高热 + 高争议**

甚至：

> **赚钱 + 伤IP**

因此以后不能拿：
- 热度
- 首日播放
- 播放量

单独证明某种叙事机制成功。

# Acquisition ≠ Retention ≠ Satisfaction

# 五、一个新的“IP遮蔽效应”

工作概念：

# IP Masking｜IP遮蔽

定义：

> 强IP/演员/前作情感资产，使一部续作即使叙事满意度下降，仍然能在首发热度、收藏或商业回收上维持不错数据。

《以爱为家3》是当前典型候选。

公开报道直接指出：
前两季累计观看超30亿，
第三季首日热度6140万；
与此同时，评论区出现“散、乱、拖”等集中批评。

来源：
https://m.sohu.com/a/1062046115_121924583

所以：

不能用首发高热反驳Reward Debt。

# 六、另一个重要反例：商业结果不是纯叙事结果

《昼以继夜2》出品方称：
成本约350万元，
上线不到15天接近打平。

来源：
https://www.thepaper.cn/newsDetail_forward_33999162

所以商业结果至少还受：

- 成本
- 演员价格
- 宣发
- 平台激励
- 系列奖励
- 长尾播放
- 海外/其他版权

影响。

因此：

Reward模型只解释**内容消费机制的一部分**，
不能伪装成完整ROI公式。

---

# 七、真正应该拿什么验证Reward模型

优先级从高到低：

1. 分集留存曲线
2. 人均观看集数/时长
3. 完播率
4. 哪一集流失
5. 评论中“拖/水/没进展”的时间点
6. 复看
7. 下一季预约/实际回流
8. 收藏
9. 点赞
10. 总播放/首日热度

总播放和首发热度仍有价值，
但它们更接近A1，不应该单独证明A2/A3。

---

# 八、模型现在真正想解释的问题

不是：

“什么剧会爆？”

而是：

> **观众为什么愿意继续把时间交给这个故事？**

这是一个更窄，
但也更能直接指导编剧的问题。

完整路径：

Hook获得下一集  
→ Reward证明刚才没白看  
→ Arc证明故事在向某处前进  
→ State Retention证明改变没有被重置  
→ Satisfaction形成  
→ Franchise Trust积累

这个链条如果成立，
才是“内容价值洼地”转化成长期IP价值的关键。
