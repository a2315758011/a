# 三、一个只能叫“信号”的试算

用“点赞数 / 热度”做非常粗的归一化，仅用于防止只看绝对热度。

复杂关系3部：
- 东北婆婆，笑护全家：约0.062
- 移巢：约0.128
- 老公的工资，婆婆的账：约0.059

中位数：
约 **0.062**

传统外部补偿6部：
中位数约 **0.0165**

这个差异看起来很大，但**不能据此宣称复杂叙事互动率更高**。

原因：

1. 样本不是随机抽取；
2. 只有3 vs 6；
3. 不同作品上线时间不同；
4. 点赞、热度指标定义并不完全透明；
5. 演员、宣发、题材、平台分发均未控制；
6. 《离婚后，爸妈带我走上巅峰》本身就是强反例——传统补偿结构同样能获得极高点赞。

因此当前结论只能是：

> **复杂关系/后半程作品至少没有表现出“市场天然排斥”的迹象。**

不能说：
> “复杂后半程比传统爽剧更赚钱/更受欢迎。”

# 五、行业级独立交叉验证

## CSM 2026中国微短剧用户年度调查

调查由西安交通大学新闻与新媒体学院、中国日报社海媒研究院、中国广视索福瑞媒介研究联合开展。

核心结果：

- 超35%的用户认为行业存在“同质化、套路化”“情节夸张脱离现实”“题材缺少创新”等问题；
- 只有52.4%的用户认同当前微短剧“内容有深度”；
- 用户希望更多看到真挚情感、自我成长、人际互助、温暖治愈等内容，这些选项均超过36%；
- 84.2%的用户表示未来愿意付费观看微短剧。

来源：
https://www.csm.com.cn/Content/2026/08-11/20260811-01.html

这与我们的方向形成独立交叉：

> 市场并不只是需要更多“爽点”，同时存在对现实连接和深层情感的需求。

但它仍不能证明“后遗层”就是最佳商业解法。

# 六、当前可保留的新假设

不是：

**深度 > 爽感**

而是：

# “爽感”正在分化。

传统爽感：
- 对手受罚
- 财富/身份翻转
- 新伴侣

新型回报：
- 我终于守住一次边界
- 一段关系终于被重新理解
- 家庭责任终于被重新分配
- 我第一次做出没人要求我的选择
- 某个人终于准确看见我的付出

行业数据说明：
用户正在要求更多现实、情感和自我成长。

反例作品说明：
这些回报可以进入高热作品。

但真正的商业优势仍需A/B/C实验验证。

# 七、下一步

从“回报类型”继续下沉到：

# Reward Cadence｜回报节奏

对高热反例和传统爽剧分别测：

- 第一次回报发生第几集；
- 每10集回报次数；
- 连续无回报最长区间；
- P1—P3和P4—P8是否交替；
- 复杂心理第一次出现后多久得到可见行动结果。

因为短剧商业化真正可能要求的不是：
“必须用哪一种爽点”，

而是：

> **无论哪一种回报，都必须在足够短的时间内被观众感知。**
