# 28部短剧回报机制逐剧编码 V0.1

日期：2026-10-26

## 一、编码规则

基于当前28部样本的**公开剧情简介**做保守编码。

只标记简介中能够明确看见的回报，不因为我们“觉得人物应该成长”就补码。

P1 复仇/惩罚  
P2 财富/身份/事业补偿  
P3 新爱情补偿  
P4 微型自主性胜利  
P5 解释性回报  
P6 关系重组回报  
P7 身份形成回报  
P8 情绪/尊严确认回报

注意：
公开简介天然更容易突出反派、财富、身份、爱情、结局，因此可能**系统性低估P4—P8**。
后续若能取得完整剧集或更详细分集剧情，必须重编码。

# 四、最重要的不是“复杂回报少”，而是“混合型已经存在”

11部样本同时存在传统回报与P4—P8。

这说明未来产品不是必须二选一：

A. 爽  
B. 深

更可能的机会是：

# Hybrid Reward Stack｜混合回报栈

先用：
- 真相
- 反击
- 财产
- 关系悬念

维持即时节奏，

再持续兑现：
- 自主性
- 关系重组
- 身份形成
- 被理解

这比“彻底取消传统爽点”更符合当前短剧媒介。

# 五、当前最稀缺的两种回报

## P5 解释性回报
当前仅2/28在公开简介中明确成立。

它的核心不是剧情反转，而是：
**同一段过去获得新的道德意义。**

## P6 关系重组回报
当前4/28明确成立。

它不是：
离开旧关系 / 换一个更好的人。

而是：
**规则、责任、资源和权力真的重新分配。**

这两类目前尤其值得继续扩样。

# 六、下一轮编码要求

必须增加：

- 每部至少3个分集/情节点，而不只看总简介；
- 回报发生频率；
- 第一次回报出现集数；
- 最大回报距离；
- P1—P3与P4—P8是否交替；
- 回报是否真正由主角选择带来；
- 回报是否被外挂/身份反转替代。

这样才能从“结局类型”进入真正的**节奏结构研究**。
