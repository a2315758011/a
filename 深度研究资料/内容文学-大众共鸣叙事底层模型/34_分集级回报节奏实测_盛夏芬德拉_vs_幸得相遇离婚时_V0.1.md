# 二、编码不是“这一集好不好看”

当前试验定义：

如果一集明确给观众至少一种新的可感知兑现，则记为“Reward Episode”。

包括：

1. 角色得到实际保护/尊重/确认；
2. 关系状态发生变化；
3. 主角获得新的选择权、能力、资源或身份；
4. 对手遭受明确挫败；
5. 一个关键误解被解除；
6. 过去事件获得新的解释；
7. 主角获得能影响后续选择的自我认识。

不计：

- 纯重复受虐；
- 单纯吵架但局势不变；
- 只制造悬念；
- 相同情绪重复表达；
- 没有改变任何后续状态的空转事件。

注意：
这是第一轮研究者编码，不是经过多编码员信度检验的标准量表。

# 四、但26—32集暴露了编码错误

如果仅用“正向关系推进”判断，
26—32会看起来像7集回报断流。

实际上这一段发生：

- 母亲死亡原因被重新激活；
- 婚姻恐惧加深；
- 女主开始把男主的好解释成“婚约义务”；
- 内心决定逃离；
- 恐惧终于压倒爱情。

这些不是甜蜜或胜利，
但它们持续增加：

# Meaning Payoff｜意义回报

观众越来越清楚：

> “她为什么明明爱，却一定要离开。”

所以：

**正向回报停了 ≠ 总回报停了。**

这是本轮最大的模型修正。

# 六、两部剧真正的差别不是“回报多 vs 少”

粗编码反而显示：

两部作品的Reward Episode密度都不低。

差别主要在**回报类型**。

## 《盛夏芬德拉》
主要回报：

- 被尊重
- 被理解
- 关系距离缩短
- 关系边界被尊重
- 创伤原因被说清
- 爱意得到更准确确认

即：
P5 / P6 / P8为主。

## 《幸得相遇离婚时》
交替使用：

- 男主救场
- 对手吃瘪
- 职业能力恢复
- 事业胜利
- 关系推进
- 身份/保护确认
- 最终司法惩罚

即：
P1/P2 与 P6/P7/P8混合。

所以：

> **传统爽剧和慢热情感剧都可能维持高Reward Density，只是它们给观众发的“奖励货币”不同。**

# 七、一个新的实测结论

## 传统爽剧
更像：

危机  
→ 外部救场/反击  
→ 新危机  
→ 事业/身份回报  
→ 新危机  
→ 情感回报。

奖励跨通道切换。

## 慢热关系剧
更像：

关系试探  
→ 一个小确认  
→ 新的不确定  
→ 新的照顾/理解  
→ 创伤暴露  
→ 解释增加  
→ 关系重新确认。

虽然大事件少，
但“意义和关系变化”仍高频。

# 八、第一版RG指标为什么不够

如果只算：

“两个正向奖励之间隔几集”

会误判《盛夏芬德拉》26—32。

因此必须拆成：

- RG_external：外部胜负回报间隙
- RG_relation：关系回报间隙
- RG_agency：自主/身份回报间隙
- RG_meaning：解释/意义回报间隙

真正危险的是：

# Global Reward Gap

即：

> **所有回报通道同时停止。**

如果：
关系不前进，
真相也没增加，
主角没有新选择，
对手也没变化，
身份没有变化，

那才是真正的“水”。

---

# 九、两种“慢”必须分开

## 有效慢

某一通道停止，
另一通道持续推进。

例如：

甜蜜关系暂停  
→ 创伤原因不断被揭开。

## 无效慢

所有通道同时停滞：

- 误会重复
- 同一场争吵换地点重演
- 主角知道的东西没增加
- 观众知道的东西没增加
- 关系状态没变化
- 现实规则没变化

这种才是真正的Reward Debt累积。

---

# 十、当前不能下的结论

不能说：

- 盛夏芬德拉“74%回报密度”是行业最优值；
- 幸得相遇离婚时“68%”就比它差；
- 回报集越多越好；
- 7集空档就是观众容忍极限。

原因：

1. 编码来自公开文字拆解，不是逐帧观看；
2. 两部剧题材、时长、受众不同；
3. Reward Episode只是二元编码，没计算强度；
4. 没有编码员一致性；
5. 没有逐集留存数据。

本轮真正能保留的是：

> **成功的慢剧并非回报少，而是回报的货币发生了变化。**
