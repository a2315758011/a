# 后半程短剧实验框架 V0.2

日期：2026-10-26

## 一、为什么优先短剧

当前供给扫描显示：
短剧在“觉醒、反击、离婚、断亲、新生”上高度成熟，
但对正确行动之后的复杂残留处理较少。

这意味着可以直接使用成熟题材完成用户识别，
再把真正创新放在“后半程”。

原则：

> **题材不新，故事阶段新。**

---

# 二、三个优先实验原型

## 实验A：边界之后的坏女儿

### 上游成熟题材
长女 / 重男轻女 / 原生家庭 / 养老责任。

### 主流版本
父母偏心
→ 女儿被吸血
→ 女儿觉醒
→ 拒绝养老/法律维权
→ 父母后悔
→ 女儿新生。

### 后半程版本

第一集就已经完成边界。

真正故事从：
女主第一次对母亲说“不”
之后开始。

核心冲突不是：
父母还能不能强迫她。

而是：

- 她拒绝后整夜失眠；
- 弟弟开始承担责任后怨恨她；
- 亲戚说她冷血；
- 母亲生病时她不知道“合理责任”和“再次被吞没”的边界；
- 她每一次维护自己，都需要重新承受“我是坏女儿”的感觉。

### 一句话

> **她已经学会拒绝父母，却还没学会承受父母因为她的拒绝而难过。**

### 测试指标
- “这就是我”的评论
- 观众是否讨论自己的边界罪感
- 是否出现长评论而非简单爽感
- 完播是否因“没有即时打脸”下降

# 三、实验B：自由以后，没有一个现成的我

### 上游成熟题材
讨好型人格 / 乖孩子 / 父母期待 / 做自己。

### 主流版本
意识到被控制
→ 拒绝期待
→ 辞职/分手/离开
→ 找到真正梦想
→ 活出自己。

### 后半程版本

女主离开了父母安排的稳定工作。

但她并没有：
- 隐藏的天赋
- 梦想职业
- 立刻出现的新方向。

她第一次拥有整整一个月没有任何人规定她该做什么，
却越来越焦虑。

别人问：
“那你到底想干什么？”

她答：
“我不知道。”

真正故事是：
**一个过去从未被允许探索的人，怎样在没有答案的情况下慢慢生成偏好。**

### 一句话

> **自由不是终于可以做自己，而是第一次发现自己还没有长出来。**

### 测试风险
这类故事缺少强外部反派，短剧节奏可能弱。

必须用：
- 微选择
- 失败试错
- 社会评价
- 收入下降
- 旧身份诱惑

制造戏剧冲突。

# 四、实验C：爱你，但不再无限负责

### 上游成熟题材
长女 / 照护者 / 家庭支柱 / 母职。

### 主流版本
责任过度
→ 觉醒
→ 切断
→ 自由。

### 后半程版本

主人公不是要离开家人。

她要做的是更困难的事：

> **继续爱，但重新谈判责任。**

例如：
- 父亲失能；
- 女主愿意承担部分照护；
- 但拒绝成为唯一照护者；
- 弟弟说“你怎么这么计较”；
- 父亲说“我养你这么大”；
- 她自己也觉得计算时间/金钱很冷血；
- 最终冲突不是“爱不爱”，而是“爱能不能有上限”。

### 一句话

> **她不是想逃离家人，她只是第一次要求：爱她的人，也必须承担爱她的代价。**

# 五、A/B对照不是比文笔

每个原型要做两版：

## A版：成熟爽剧结构
- 反派清晰
- 觉醒
- 反击
- 胜利
- 快速情绪兑现

## B版：后遗层结构
题材、角色、开场钩子尽量保持一致，
只把后半段改成：
- 内疚
- 身份残留
- 系统反弹
- 现实责任
- 新自我形成

比较：

1. 首集停留
2. 3集留存
3. 10集留存
4. 长评论率
5. 自我叙述评论率
6. 收藏
7. 分享给具体对象
8. “爽”评价
9. “像我/说的是我”评价
10. 后续同系列消费意愿

---

# 六、一个重要预测

A版可能赢：
- 即时完播
- 爽感
- 打脸评论

B版可能赢：
- 长评论
- 收藏
- 自我叙述
- 系列追更
- 人物长期关系

这只是工作假设。

如果真实实验显示：
B版留存、互动和追更全面弱于A，
就必须接受：
“现实更深”不等于“内容更值钱”。

---

# 七、未来IP结构

如果后遗层成立，
它天然适合系列化：

第一季：
看见问题。

第二季：
做出行动。

第三季：
承受行动代价。

第四季：
重新形成自我。

第五季：
带着新边界进入新的关系。

这比“不断换一个坏人打脸”更有长期人物弧线潜力。

---

# 八、当前最值得测试的一句话

不是：
“离开伤害你的人。”

而是：

> **“很多故事都教你怎么离开，却很少有人告诉你：离开以后，你还要和那个被训练了很多年的自己一起生活很久。”**

这句话可以作为当前“叙事后遗层”总假设的B版本刺激材料。
