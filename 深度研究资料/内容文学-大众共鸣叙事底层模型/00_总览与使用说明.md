# 内容文学：大众共鸣叙事底层模型

版本：V1.0  
建立日期：2026-10-26  
目标：研究“人为什么会在别人的故事、歌曲、角色和一句话里认出自己”，并把结论转化为可复用的原创内容生产系统。

## 研究边界

本项目不把“共鸣”简单等同于感动、悲伤、爆款或商业成功。至少拆成七个过程：

1. 自我相关：内容是否与“我是谁/我经历过什么”发生连接。
2. 自传记忆：内容是否唤醒真实的人生片段。
3. 身份匹配：角色的心理处境是否像“我们这种人”。
4. 自我差距：现实自我与理想自我/应然自我之间是否形成张力。
5. 叙事沉浸：观众是否进入人物的因果链、想象与情绪。
6. 情绪命名与释放：作品是否替观众把模糊感受说清楚。
7. 社会传播与行动：观众是否愿意评论、转发、关注、付费或把作品纳入自我表达。

## 核心判断

共鸣的最小单位不是“题材”，而是“人生经验结构”。

“失恋”“亲情”“职场”“修仙”“逆袭”都只是外壳。真正跨媒介稳定的结构更像：

- 我努力了很久，却一直没有被看见。
- 我真正失去的不是一个人，而是一个以为会发生的人生。
- 我终于成为别人期待的人，却越来越不像自己。
- 我终于成功，但最想让他看到的人已经不在了。
- 我一直怪一个人，直到有一天我活成了他当年的处境。

## 当前综合模型

暂称 **SELF-NARRATIVE RESONANCE LOOP（自我叙事共鸣环）**：

外部内容
→ 自我相关线索
→ 自传记忆/自我差距被激活
→ 心理处境匹配
→ 角色认同与叙事沉浸
→ 情绪被命名/重新解释
→ 获得“这就是我”的识别感
→ 产生评论、分享、复看、关注等社会行为
→ 内容反过来进入个人身份叙事。

这是一套跨理论综合框架，不是单篇论文已证明的统一定律。每个环节都必须分别验证。

## 使用原则

任何新内容先回答三问：

1. 这是在讲谁的人生？
2. 观众在哪一个具体瞬间认出自己？
3. 认出自己以后，为什么会评论、分享、继续追、关注或付费？

如果只能回答“因为很感人/很真实/很爽”，说明分析仍停留在表层。
