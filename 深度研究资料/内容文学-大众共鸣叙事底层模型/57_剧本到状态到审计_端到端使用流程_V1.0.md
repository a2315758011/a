# 剧本→状态→审计 端到端使用流程 V1.0

日期：2026-10-26

## 一、输入

准备：

- narrative_state.json
- script.md

其中 narrative_state.json 必须是当前正式Canon。

---

# 二、第一步：文本抽取

命令：

python 53_script_to_state_parser.py extract script.md extracted.json

输出：

extracted.json

包含：

- episodes
- scenes
- characters
- candidate state changes
- commitments
- reward channels
- scene contract drafts

重要：

这里所有语义结果都是候选。

---

# 三、第二步：生成Draft Delta

命令：

python 53_script_to_state_parser.py compile narrative_state.json extracted.json draft/

输出：

draft/episode_delta_draft.json
draft/scene_contracts_draft.json

这些文件默认含：

review_required=true

所以：

不能直接Commit。

---

# 四、第三步：语义审查

对每个candidate判断：

## FACT
客观事实。

## BELIEF
只是某角色相信。

## MISUNDERSTANDING
角色相信，但世界事实相反或未知。

## EMOTION
情绪表达，不构成事实状态。

## STATE_CHANGE
真实改变边界、关系、能力、身份、资源或弧线。

## NO_CHANGE
只是重复说明，不入账。

同时补：

- state_id
- before
- after
- cause
- evidence
- transition_class

transition_class只能是：

- retain
- relapse
- revision
- strategy

如果实际属于reset：
不要把review_required改成false，
而应交给Auditor阻断。

---

# 五、第四步：移除候选态

只有审查完成的条目：

review_required=false

或移除该字段。

未通过的候选：
直接删除。

---

# 六、第五步：Narrative Auditor

命令：

python 48_narrative_auditor_reference.py narrative_state.json approved_delta.json approved_scene.json

结果：

## PASS
允许进入Commit。

## REPAIR
存在可局部修复问题。

## BLOCK
禁止进入Canon。

---

# 七、第六步：Commit

只有PASS：

Canon Version + 1。

然后写回：

- timeline
- character knowledge
- boundary
- relationship
- competence
- identity
- resource
- arc state
- commitments
- reward state

并保存：

Episode State Delta。

---

# 八、错误使用方式

禁止：

script.md
→ Parser
→ 直接更新Canon

正确：

script.md
→ Parser候选
→ Semantic Review
→ Auditor
→ PASS
→ Canon

---

# 九、目前系统的实际定位

53_parser：
高召回候选发现器。

Semantic Reviewer：
语义裁决器。

48_auditor：
一致性和门禁执行器。

State Store：
唯一正式事实源。

四者不能合并成“一个AI随便判断”。

---

# 十、下一阶段

下一阶段实现：

# Semantic Reviewer V1

输入：
- candidate
- local scene context
- current state slice

输出：

- classification
- target state_id
- before
- proposed_after
- transition_class
- confidence
- evidence
- approve / reject / escalate

重点解决：

“角色说了一句话”
到底是：
- 世界事实
- 角色认知
- 错误认知
- 情绪
- 承诺
- 真正状态变化

这是自动剧本审计从规则层进入语义层的关键。
