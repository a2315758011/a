# 第2集：两天就是两天

场景1 医院病房

护士：今晚需要一位家属陪护。

母亲：你弟弟工作忙，你就多陪几天吧，反正你请假也方便。

林晚：我今天留下，但我最多陪两天，明天让林海来。

林海：姐，你就不能再帮一次吗？我最近项目真的很忙。

母亲：我就知道，女儿嫁出去以后心就不在家了。

林晚沉默了几秒，拿出手机，把护工电话发进家庭群。

林晚：费用我出一半，时间我们一人一半。我可以帮，但不能再全由我承担。

场景2 医院走廊

林晚走出病房，手一直在抖。

她第一次清楚意识到，母亲难过并不等于自己的决定是错的。

她决定明天照常去上班。

林海看着家庭群里的排班表，最终在“周二、周四、周六”三晚后面写下自己的名字。

场景3 电梯口

母亲给林晚发来一条语音：“医药费你弟弟最近手头紧，你先垫一下吧。”

林晚没有回复。

电梯门合上。
